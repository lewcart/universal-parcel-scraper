# A1 POST

A1 POST parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

A1 POST is the shipping brand of A1 Trade in Varna, Bulgaria. Its tracker shows A1 POST's own
scans in Bulgaria and the events of the partner carrier abroad under the partner's label
number. A parcel bound for the United States carries a USPS label number, which USPS detection
names, so A1 POST adds no rule.

## Links

The tracker page renders one parcel from its `t` parameter, as an archived lookup on A1 POST's
own site shows.
