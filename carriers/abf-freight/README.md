# ABF Freight

ABF Freight shipments use enabled universal providers. There is no dedicated adapter.

## Numbers

ABF PRO numbers in aggregator samples are nine digits. Nine digits are shared with several
carriers, so no rule claims them.

## Links

ABF tracks through ArcBest's tool, which opens a PRO number from the address hash at
`view.arcb.com/nlo/tools/tracking#/{number}`.

## Testing

Provider live-test inputs and commands are in the [provider READMEs](../../providers/README.md).
