# ACS Courier

ACS Courier parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

ACS Courier numbers are ten digits, as Trustpilot reviews and an aggregator page show. Ten
digits are shared with several carriers, so no rule claims them.

## Links

ACS's public shipment search reads numbers from `?trackingNumber=` and searches on load.
