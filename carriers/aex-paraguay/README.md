# AEX

AEX parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

AEX (COPASSA S.A.) is a Paraguayan courier. A guía is a series code followed by its number;
guías seen on its tracker are the letter A and nine digits. Detection does not offer AEX, since
that shape falls inside Allegro One's rule.

## Links

The tracker at `www.aex.com.py/web/tracking.php` reads the guía from `guia`. Archived lookups
also open one at `/web/tracking/` followed by the guía.
