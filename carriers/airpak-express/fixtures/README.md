# Fixtures

Each fixture follows Airpak's page for one number, `go/plm-tracking?stid=airpak&cn=`, trimmed to
the markup around the history and the script the server writes it into, block for block as the
page writes it.

`delivered.html` is a twelve-digit connote collected and delivered in Malaysia, under the page's
four sections: an uplift from a location that names the country alone, failed attempts, a hold
in the depot, a wait for a collection by the recipient and a delivery with the masked signatory.
The page also carries a service type and a sender's reference. `in-transit.html` is an
eleven-digit connote from Singapore on its way through Malaysia, with the documents prepared
before the collection and an uplift at midnight. `not-found.html` is the page for a number the
tracker holds nothing for.

Numbers, references, places, clocks and the signatory are invented.
