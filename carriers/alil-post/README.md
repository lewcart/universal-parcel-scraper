# Alil Post

Alil Post parcels use enabled universal providers. There is no dedicated adapter.

Alil Post sends express parcels from Israel to Ukraine, the European Union, the United States, Canada,
Georgia, Moldova and other countries. Its site is alilpost.com.

## Numbers

Its tracker takes Alil Post's own invoice number. No public number is known, so there is no rule.

## Why there is no adapter

The tracker asks an open form service with the number alone, without a login or CAPTCHA, and shows
the scans of the Nova Poshta shipment that carries the parcel. No public number has shown a known
reply yet. An adapter can follow.

## Links

The tracker has no per-shipment address, so there are no tracking links.
