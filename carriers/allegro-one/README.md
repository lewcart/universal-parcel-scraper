# Allegro One

Allegro One and Allegro Delivery parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Allegro One numbers are ten letters and digits starting `A0`, such as `A000MFPFX6`, and
Allegro Delivery numbers start `AD`, such as `AD01EIJLQ4`. Sellers and buyers quote both on
Allegro's community forum, and a Trustpilot review quotes another. `allegro-one-1` claims
`A0` or `AD` followed by eight letters and digits. Allegro publishes no check digit.
