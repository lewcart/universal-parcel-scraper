# American West

American West parcels use enabled universal providers. There is no dedicated adapter.

American West (AWest) is a furniture and e-commerce home delivery carrier based in San Luis
Obispo, California. Its I-Trek tracker looks up an AWest pro number, a shipper bill of lading,
a consignee purchase order or a consignee phone number and shows the pickup, the ETA to the
final mile hub and the delivery.

## Numbers

An archived lookup on the carrier's own tracker shows a pro number of two letters and seven
digits. Other carriers print the same shape, so no rule claims it and a gap declaration covers
the layout.

## Links

`awest.freightgate.com/cgi-bin/tarifftrek5.1/itrek.cgi` with the number in `open_text` and
`SearchOn=open_billno` opens one shipment: an archived lookup on the carrier's tracker uses it.
The tracker only finds shipments picked up in the past 90 days.
