# ANNTO

ANNTO parcels use enabled universal providers. There is no dedicated adapter.

ANNTO (安得智联), the logistics arm of the Midea group, stores, carries and delivers goods across China,
including last-mile delivery and installation of appliances. Its site is annto.com.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

Its waybill query on annto.com takes numbers separated by commas and looks them up without a login; frequent
lookups bring up a verification code. No public number is known to see a found reply.

## Links

Tracking links carry the number as `orderNoFormMain` on its order page.
