# APC Overnight

APC Overnight parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

A seller gives an APC Overnight consignment number of twenty-two digits. One sample does not
establish a rule.

## Links

APC's tracker asks for the consignment number and a postcode, so the user enters both on
`apc.co.uk`.

Provider live-test inputs and commands are in the [provider READMEs](../../providers/README.md).
