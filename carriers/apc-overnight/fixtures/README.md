# Fixtures

`journey.html`, `returned.html` and `delivered.html` follow the shape of APC Choice's tracking
page for one waybill: the delivering depot, the consignment summary, and for each item its
journey and the consignment's delivery records. `delivered.html` is an older consignment whose
journeys have aged out. `not-found.html` is the search page APC sends back for a waybill it does
not have and `invalid.html` the one for an identifier of the wrong shape. Waybills, depots,
references, weights and clocks are invented.
