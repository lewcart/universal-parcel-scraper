# APG Global

APG Global parcels use enabled universal providers. There is no dedicated adapter.

APG Global, in Miami, ships mail and online orders to Latin America, Brazil above all, and clears
them through customs, with hubs in the United Kingdom, Europe, Asia and Australia. It was formed as
APG International in 2018 from Aprisa Express and Pakya. APG eCommerce Solutions, Australia Post's
consolidator, is a different company. Its site is apg-global.com.

## Numbers

Its tracker, MIRA Track, takes the numbers of the destination posts that deliver, such as Correios'
S10 numbers, and its own references. The example it prints is a Correios number it no longer finds.
The postal rules read S10 numbers, so there is no rule.

## Why there is no adapter

The tracker reads up to fifty numbers from its address and draws its answer on the server without a
login or CAPTCHA. No public number has shown a known parcel's reply yet.

## Links

Tracking links carry the numbers as a JSON list in `trackings` on the tracker's Track page.
