# Aras Kargo

Aras Kargo parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Aras Kargo numbers in Şikayetvar complaints are thirteen digits starting `60` or `65`; one
complaint gives fourteen digits. Neither length is distinctive, so no rule claims them.

## Links

Aras Kargo tracks from a field on its home page that posts the number, so no link opens one
parcel.

## Testing

Provider live-test inputs and commands are in the [provider READMEs](../../providers/README.md).
