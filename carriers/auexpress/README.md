# AuExpress

AuExpress parcels use enabled universal providers. There is no dedicated adapter.

AuExpress (澳邮), the trading name of STS Logistics (Australia), based in Sydney with a Melbourne branch, ships
parcels and freight between Australia and China. Its site is auexpress.com.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

Its tracking page is a single-page app that looks an order number up without a login. No public number is
known to see a found reply.

## Links

Tracking links carry the number as `OrderId` on its tracking page.
