# Bangladesh Post Office

Bangladesh Post Office parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

International items, EMS included, carry UPU S10 numbers ending in `BD`. Generic postal
detection handles them, so no rule of its own claims them. The tracker's domestic option takes
the same layout.

## Links

The tracker on ipsbd.bdpost.gov.bd sends the number in a form post, so no address opens one
item.
