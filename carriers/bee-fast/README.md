# BeeFast

BeeFast parcels use enabled universal providers. There is no dedicated adapter.

BeeFast is an Australian transport, warehousing and distribution company with depots in Sydney,
Melbourne, Brisbane, Adelaide and Perth. Its sister brand TE Express uses the same tracking
system. Its site is beefast.com.au.

## Numbers

Its tracking page asks for a BeeFast reference. The page's example, two letters and six digits,
is made up and no public reference is known, so there is no rule.

## Why there is no adapter

The tracking page posts the reference to an open JSON service without a session, login or
CAPTCHA. No public reference has shown a known parcel's reply yet. An adapter can follow.

## Links

The tracking page looks references up in place, so no address names one.
