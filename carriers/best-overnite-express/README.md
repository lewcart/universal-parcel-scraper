# Best Overnite Express

Best Overnite Express parcels use enabled universal providers. There is no dedicated adapter.

Best Overnite Express is a family-run regional LTL carrier based in Southern California. It
also runs residential and unattended deliveries.

## Numbers

Shipments are traced by the carrier's PRO number, eight digits on the archived trace, or by an
interline PRO with the partner's SCAC. Bare eight-digit numbers are shared by many carriers,
so no rule claims them.

## Links

The classic trace takes the PRO number in `wbfb` on `cgi-bin/wbprotrk`, on
`tgif.bestovernite.com` and formerly on `www.bestovernite.com`; the library reads the number
from that address. The current tracking page uses a script widget with no number in its
address.
