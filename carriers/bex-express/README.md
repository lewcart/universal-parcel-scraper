# BEX Express

BEX Express parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

BEX Express shipment numbers have nine digits, as its tracking form's example and archived
lookups show. Nine digits are shared with other carriers, so no rule claims them.

## Links

The tracking page reads the number from `broj-posiljke` and loads the history from BEX's
tracking service.
