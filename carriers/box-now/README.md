# BOX NOW

BOX NOW locker parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

BOX NOW numbers in reviews of its Greek and Bulgarian sites are ten digits. Ten digits are
shared with several carriers, so no rule claims them.

## Links

BOX NOW's Greek site blocks automated checks, so its search page is the same tracker on
`boxnow.cy`. The tracker posts the number, so no link opens one parcel.
