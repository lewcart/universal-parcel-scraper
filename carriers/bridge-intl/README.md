# Bridge Intl

Bridge Intl parcels use enabled universal providers. There is no dedicated adapter.

Bridge Intl (珀斯宏桥国际速递), based in Perth, ships parcels, luggage and furniture between Australia and
China and delivers door to door within Australia. Its site is bri-ems.com.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

Its query page looks a number up through `getorder.php` without a login and shows the reply in place. No
public number is known to see a found reply.

## Links

Its query page looks numbers up in place, so no address names one.
