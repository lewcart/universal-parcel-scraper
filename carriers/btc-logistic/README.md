# BTC Logistics

BTC Logistics parcels use enabled universal providers. There is no dedicated adapter.

BTC Logistics, run by Bander Trading Company (شركة بندر التجارية) since 2019, is a Saudi transport
and delivery company with branches in Tabuk, Jeddah, Riyadh, Dammam and Abha that delivers for
online shops and platforms. Its site is btclogistic.com.

## Numbers

Its tracker accepts thirteen digits. No public number is known, and other carriers' rules read
thirteen digits too, so there is no rule.

## Why there is no adapter

The tracker on its home page loads a number's history as a bare page without a session or CAPTCHA,
and says when a number is invalid. No public number has shown a known shipment's reply yet. An
adapter can follow.

## Links

Tracking links carry the number in the path after `/order_history/`, the bare history its home page
shows in a window.
