# BTS Express

BTS Express parcels use enabled universal providers. There is no dedicated adapter.

BTS Express is an Uzbek courier with a national office network and international shipping.

## Numbers

Its tracker asks for the barcode (shtrix-kod). The barcodes in its API documentation are eleven
and twelve digits ending in the order id. Such digit runs are printed by many carriers, so no
rule claims them.

## Links

The tracker posts the barcode with a captcha answer, so no address opens one parcel.
