# C3X

C3X parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

C3X is a Dubai courier of the Bin Yaber Group. Its API documentation shows ten-digit
airwaybills. Ten-digit runs are shared by many carriers, so no rule claims them and the gap is
declared.

## Links

The tracking field on `c3xpress.com` sends the number to C3X's API and shows the history in
place. No address opens one parcel.
