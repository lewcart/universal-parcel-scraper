# CARRY FLAP

CARRY FLAP parcels use enabled universal providers. There is no dedicated adapter.

CARRY FLAP (キャリーフラップ株式会社), based in Nagoya, delivers shippers' parcels of up to 20 kg to
businesses in Aichi, Mie, Gifu, Nagano, Shiga and Shizuoka in mixed loads, with contracted
drivers and its own delivery system, CarrySEARCH. Its site is carry-flap.com.

## Numbers

Its tracker asks for an inquiry number (問い合わせ番号). No public page shows one or states its
layout, so there is no rule.

## Why there is no adapter

The tracker asks an open JSON service, which takes several numbers at once without a session. No
public number has shown a known parcel's reply yet. An adapter can follow.

## Links

Tracking links carry the number as `invoiceNo` in the tracker's address after `#/home`.
