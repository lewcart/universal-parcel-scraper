# CBL Logística

CBL Logística parcels use enabled universal providers. There is no dedicated adapter.

CBL Logística is a Spanish road transport and logistics company with its own network across
Spain and Portugal.

## Numbers

A customer's review gives an eleven-digit shipment number. Eleven bare digits are shared with
other carriers, so no rule claims them.

## Links

The public lookup at clientes.cbl-logistica.com takes a locator in a form and loads the result
by script, so no address opens one parcel.
