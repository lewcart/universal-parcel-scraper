# CDEK

CDEK parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

CDEK order numbers are eleven digits starting `10`, as reviews and a complaint article quote
them. Eleven digits are shared with several carriers, so no rule claims them. CDEK Forward
parcels from abroad also carry the sender country's S10 number, which stays with the generic
postal carrier.
