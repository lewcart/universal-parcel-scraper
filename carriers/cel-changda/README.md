# CEL Changda

CEL Changda parcels use enabled universal providers. There is no dedicated adapter.

CEL Changda (畅达), run by Hunchun Changda E-commerce and its Shenzhen arm, carries online orders from
China to Russia, with customs clearance and warehouses in Russia. Its site is celdt.cn.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

Its tracker on tms.celdt.cn is an ASP.NET page that takes several numbers and asks for an image code when it
chooses to. No public number is known to see a found reply.

## Links

Its tracker looks numbers up by posting its form, so no address names one.
