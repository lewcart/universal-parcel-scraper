# ChangJiang Express

ChangJiang Express parcels use enabled universal providers. There is no dedicated adapter.

ChangJiang Express (长江国际速递), based in Melbourne, ships parcels from Australia to China, packed to
Chinese customs rules for personal parcels. Its site is changjiangexpress.com.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

Its tracker posts up to ten numbers, one per line, with a four-digit image CAPTCHA to `Home/Query`. No public
number is known to see a found reply.

## Links

Its tracker looks numbers up by posting its form, so no address names one.
