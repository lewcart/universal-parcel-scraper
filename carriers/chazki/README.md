# Chazki

Chazki parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Chazki is a last-mile courier in Peru, Argentina, Chile, Colombia and Mexico. Its trackcodes
vary by sender: some are digit runs, others three letters and digits. Detection does not offer
Chazki, since no shape belongs to it alone.

## Links

The help centre at `www.chazki.com/centro-de-ayuda` opens a code at
`nintendo.chazki.com/trackcodeTracking/` followed by the code.
