# Chilexpress

Chilexpress parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Chilexpress tracks a shipment by its transport order number (orden de transporte, OT), which
its tracking help page describes as ten to twelve digits. Bare digit runs of these lengths are
printed by many carriers and nothing in the number points to Chilexpress, so no rule claims
them.

## Links

The tracking page `chilexpress.cl/Views/ChilexpressCL/Resultado-busqueda.aspx?DATA=` followed
by the number opens a shipment. The help centre uses
`centrodeayuda.chilexpress.cl/seguimiento/` followed by the number.
