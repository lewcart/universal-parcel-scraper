# China Railway Express

China Railway Express parcels use enabled universal providers. There is no dedicated adapter.

China Railway Express (中铁快运), part of China State Railway Group, carries parcels and freight on passenger
and high-speed trains across China. Its site is 95572.com.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

Its home page looks a waybill up after an image CAPTCHA. No public number is known to see a found reply.

## Links

Its home page looks numbers up in place, so no address names one.
