# Chit Chats

Chit Chats shipments use enabled universal providers. There is no dedicated adapter.

## Numbers

A Chit Chats shipment ID is ten letters and digits, such as `AB1234C5D6` on its tracking
page. Partner carriers' numbers stay with those carriers. Ten letters and digits are not
distinctive, so no rule claims them.

## Links

Chit Chats serves each shipment at `chitchats.com/tracking/{shipment ID}`.
