# Chunil Express

Chunil Express parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Chunil Express (천일택배) prints eleven-digit waybill numbers; its own tracking form accepts
only eleven digits. Other carriers print the same digit runs, so no rule claims them.

## Links

`chunil.co.kr/HTrace/HTrace.jsp?transNo={number}` shows one parcel. A tracking field on
`chunilps.co.kr` and on the parent company's home page opens it.
