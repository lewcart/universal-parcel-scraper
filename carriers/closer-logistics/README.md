# Closer Logistics

Closer Logistics parcels use enabled universal providers. There is no dedicated adapter.

Closer Logistics is a Spanish last-mile delivery company whose deliveries include Zara online
orders.

## Numbers

Public consumer complaints and a review give twelve-digit shipment numbers. Twelve digits are
shared with many carriers, so no rule claims them.

## Links

`tracking.closerlogistics.com/tracking/` followed by the number opens one parcel; the tracking
box on closerlogistics.com builds that address.
