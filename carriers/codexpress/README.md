# CODExpress

CODExpress parcels use enabled universal providers. There is no dedicated adapter.

CODExpress is an Australian courier that delivers parcels, including same-day Amazon orders,
with its own drivers. Its tracker runs on Locate2u.

## Numbers

No public source shows a whole CODExpress number, so the corpus is empty and no rule claims a
layout.

## Links

The tracker posts the number to its own lookup and reads none from its address, so no link
opens one parcel.
