# Connect Couriers

Connect Couriers parcels use enabled universal providers. There is no dedicated adapter.

Connect Couriers is a Maltese courier and freight forwarder with its own fleet on Malta and
Gozo. It also works as a sub-agent of international express networks.

## Numbers

An archived lookup on its tracker shows an eleven-digit number. Eleven bare digits are shared
with other carriers, so no rule claims them.

## Links

The tracking page at `connectcouriers.eu/tracking/` reads a `tracking_number` parameter and
looks the parcel up by script.
