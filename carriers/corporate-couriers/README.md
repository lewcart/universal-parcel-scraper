# Corporate Couriers

Corporate Couriers parcels use enabled universal providers. There is no dedicated adapter.

Corporate Couriers Logistics, based in Burnaby since 1980, runs same-day and next-day courier,
distribution and warehousing in British Columbia's Lower Mainland, on Vancouver Island and in
Alberta. Its site is corporatecouriers.net.

## Numbers

Its tracker takes numeric order numbers. No public page shows one, so there is no rule.

## Why there is no adapter

The tracker reads the number from its address and searches only the last two months. An unknown
number gets a result with every field marked not complete, and no public number has shown a
known delivery's reply yet.

## Links

Tracking links carry the number as `tracking-number` on the order tracking page.
