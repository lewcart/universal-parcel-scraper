# Correos de Cuba

Correos de Cuba parcels use enabled universal providers. There is no dedicated adapter.

The Empresa de Correos de Cuba runs the national post of Cuba.

## Numbers

Its items carry UPU S10 numbers ending in CU. Inbound items keep the S10 number of the post
that sent them. Generic postal detection handles both, so no carrier rule claims the layout.

## Links

The tracker at correos.cu asks for the number and the year of posting and loads the history
with a script, so no address opens one parcel.
