# Correos de México

Correos de México items use enabled universal providers. There is no dedicated adapter.

## Numbers

Comments on an aggregator review page quote Mexican S10 numbers. International items use the
UPU S10 layout and stay with the generic postal carrier.

## Links

Correos de México's tracker posts the number back to its page, so no link opens one item.
