# Coupang Logistics Services

Coupang Logistics Services parcels use enabled universal providers. There is no dedicated adapter.

Coupang Logistics Services (쿠팡로지스틱스서비스), set up in 2018, is Coupang's delivery company in South
Korea. It delivers Rocket orders and other parcels under its own waybill numbers. Its site is
coupangls.com.

## Numbers

Its tracker takes its own waybill numbers, typed without hyphens, not Coupang order numbers. No
public page shows one or states their layout, so there is no rule.

## Why there is no adapter

The tracker looks waybills up from its home page, but a bot manager blocks scripted requests to it,
so an adapter would need a browser.

## Links

The tracker shows its answer in a pop-up on the home page, so no address names one parcel.
