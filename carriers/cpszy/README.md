# CPSZY

CPSZY parcels use enabled universal providers. There is no dedicated adapter.

CPSZY (CPS华中转运), run by Hunter Logistics Inc. in Los Angeles, ships parcels from the United States to
China, with depots in Los Angeles, New York, New Jersey and New Hampshire. Its site is cpszy.com.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

Its waybill query reads the number from the address and shows the scans without a login or CAPTCHA. No
public number is known to see a found reply.

## Links

Tracking links carry the number as `sn` on its `trace.html` page.
