# Fixtures

The replies follow `getTrackingByNos` for one number: a JSON array with one item, its summary
status in Chinese, the countries in Chinese and the scans in English, newest first.
`in-transit.json` goes from the order data to the flight out of China, with one scan repeated.
`registered.json` has only the order data. `not-found.json` is the answer for a number CTTYEX
does not know.

Numbers, countries and clocks are invented.
