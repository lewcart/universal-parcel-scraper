# Cyprus Post

Cyprus Post items use enabled universal providers. There is no dedicated adapter.

## Numbers

An aggregator page prints a Cyprus S10 number. International items use the UPU S10 layout and
stay with the generic postal carrier.

## Links

Cyprus Post's tracker posts the numbers with a form token, so no link opens one parcel.

Provider live-test inputs and commands are in the [provider READMEs](../../providers/README.md).
