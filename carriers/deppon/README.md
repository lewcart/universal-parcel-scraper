# Deppon

Deppon parcels use enabled universal providers. There is no dedicated adapter.

Deppon (德邦) is a Chinese express and freight carrier, now part of JD Logistics. Its tracker
also follows its parcels to Taiwan.

## Numbers

Customers quote ten-digit waybill numbers. Ten digits are printed by DHL and several other
carriers, so no rule claims them.

## Links

The tracker is a single-page app that posts the number to Deppon's gateway; its address carries
no number, so no link is read.
