# DER KURIER

DER KURIER parcels use enabled universal providers. There is no dedicated adapter.

DER KURIER Slovakia, spol. s r.o., in Bratislava, is an express courier of German origin, in
Slovakia since 2002. It delivers documents and parcels across Slovakia by the next day and abroad
through partners, and also carries freight, dangerous goods and temperature-controlled loads and
handles customs. Its site is derkurier.sk.

## Numbers

Its earlier tracker took an order number. No public page shows one with its tracker's answer, so
there is no rule.

## Why there is no adapter

The tracker is behind a CAPTCHA, and plain requests get only an empty app shell.

## Links

No address of the current tracker opens one shipment, so there are no tracking links.
