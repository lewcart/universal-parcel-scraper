# Designer Transport

Designer Transport parcels use enabled universal providers. There is no dedicated adapter.

Designer Transport is an Australian last-mile and white-glove home delivery company for
furniture and other bulky goods, with depots in New South Wales, Victoria and Queensland.

## Numbers

Its tracker looks deliveries up by reference. No public source shows one, so the corpus is
empty and no rule claims a layout.

## Links

The tracker posts the reference to its own search and reads none from its address, so no link
opens one delivery.
