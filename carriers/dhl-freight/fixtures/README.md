# DHL Freight fixtures

Every number, place, weight and clock in these pages is invented. The pages keep
the shape of ActiveTracing's English answers, trimmed to the parts the parser
reads and the ones it must ignore.

- `delivered.html`: an order code's consignment details, delivered abroad, with
  day-only rows and delivery rows that name no terminal.
- `in-transit.html`: a package ID's consignment details, between terminals.
- `not-found.html`: the search page with its notice that no consignment matches.
