# DHX

DHX shipments use enabled universal providers. There is no dedicated adapter.

DHX (Dependable Hawaiian Express), based in Los Angeles, ships freight, vehicles and household
goods from the US mainland to Hawaii, Guam and Alaska by sea and air. Its site is dhx.com.

## Numbers

DHX publishes no freight bill number format, and no public page shows one of its numbers, so
there is no rule.

## Why there is no adapter

None is built yet. Its quick track page reads a freight bill or pickup tracking number through an
ASP.NET form post, with no page or address per number.

## Links

No tracking link is known.
