# Dnipro LLC

Dnipro LLC parcels use enabled universal providers. There is no dedicated adapter.

Dnipro LLC of Roselle, New Jersey, is an air and sea forwarder that ships personal parcels, goods and
vehicles from the United States to Ukraine and other countries, with warehouses in New Jersey,
Delaware and Kyiv. Its site is dniprollc.com.

## Numbers

Each parcel gets its own tracking number, whose layout its pages do not give. Parcels sent on by
post travel on that post's number. No public Dnipro LLC number is known, so there is no rule.

## Why there is no adapter

The tracker asks an open JSON service with the number alone, without a login or CAPTCHA, and answers
an unknown number with an empty list. Its replies carry recipients' names that an adapter must leave
out. No public number has shown a known reply yet.

## Links

Tracking links carry the number as `tracking` on the `packages-tracking` page at dniprollc.com.
