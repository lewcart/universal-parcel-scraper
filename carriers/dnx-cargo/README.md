# DNX Cargo

DNX Cargo parcels use enabled universal providers. There is no dedicated adapter.

DNX Cargo is an air and surface express cargo carrier serving Maharashtra, Goa and Gujarat,
India.

## Numbers

Its tracker shows nine-digit docket numbers. Nine digits are printed by many carriers, so no
rule claims them.

## Links

The tracker on `dnxerp.in` posts its form, so no address opens one docket.
