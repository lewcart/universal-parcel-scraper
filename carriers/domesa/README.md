# Domesa

Domesa parcels use enabled universal providers. There is no dedicated adapter.

Documentos Mercantiles S.A. (Domesa), founded in 1975, is a licensed Venezuelan courier that carries
documents and parcels across Venezuela. Its site is portal.domesa.com.ve.

## Numbers

Its guías are numeric, and no public guía is known, so there is no rule.

## Why there is no adapter

Its tracker sends each lookup with a CAPTCHA token.

## Links

The tracker has no per-shipment address, so there are no tracking links.
