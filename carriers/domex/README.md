# Domex

Domex parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Domex waybill numbers are digits; its API documentation shows eight and nine. Many carriers
print such runs, so no rule claims them.

## Links

The tracking forms on domex.lk open `domex.lk/Order-Details.php?wbno={number}`, and the
former tracking page read the same parameter.
