# Dragon Star Curier

Dragon Star Curier parcels use enabled universal providers. There is no dedicated adapter.

DSC Dragon Star Curier is a Romanian courier network.

## Numbers

AWB numbers are short bare digit runs: an archived lookup on DSC's former tracker shows seven
digits and a customer's review gives eight. Other carriers print the same lengths, so no rule
claims them.

## Links

The tracking page at `dragonstarcurier.ro/tracking-awb` is a GET form that reads an `awb`
parameter and opens one parcel. The AWB script of the former curierdragonstar.ro site is gone.
