# DX

DX parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

DX Secure and DX Express numbers are a letter `C`, `L` or `W` and seven digits. `dx-1` suggests
DX at low confidence, because GLS references share the length. DX Freight reviews also quote
ten-digit numbers, which no rule claims.

## Links

DX now trades from `dxlogistics.com`, whose tracking form still sends the number to
`my.dxdelivery.com/query?tracking_number={number}`.
