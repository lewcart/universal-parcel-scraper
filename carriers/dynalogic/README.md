# Dynalogic

Dynalogic parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Dynalogic track & trace numbers in public Test-Aankoop complaints are ten digits, and a review
quotes a code of five digits, two letters and six digits. Neither shape is published, so no
rule claims them.

## Links

Dynalogic's MyDynalogic tracker asks for the number and a postcode, so the user enters both
there.
