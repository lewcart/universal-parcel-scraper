# EDI Express

EDI Express parcels use enabled universal providers. There is no dedicated adapter.

EDI Express is a less-than-truckload carrier in Gardena, California. Two-driver sleeper teams run
its freight between California, Texas, the Midwest and the East Coast without break-bulk hubs. Its
site is ediexpressinc.com.

## Numbers

No public page shows one of its PRO numbers, so there is no rule.

## Why there is no adapter

Its trace page posts a PRO number to a form, and no public PRO number has been found to check a
found reply with.

## Links

Its trace page opens a single PRO number only from a form post; the address of its result asks for a
login, so no link names it.
