# EES Logistics

EES Logistics parcels use enabled universal providers. There is no dedicated adapter.

EES Logistics (百福东方), based in Beijing, carries business freight and parcels across China, including
after-sales spare parts, returns and other reverse logistics. Its site is ees-logistics.net.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

Its query page on api.eesimp.com posts an order or box number as `kw` to `imc/pub_logi_info/query` without a
login or CAPTCHA and lists each box's scans. No public number is known to see a found reply.

## Links

Its query page looks numbers up by posting its form, so no address names one.
