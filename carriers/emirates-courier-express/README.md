# Emirates Courier Express

Emirates Courier Express parcels use enabled universal providers. There is no dedicated adapter.

Emirates Courier Express is the door-to-door express service of Emirates SkyCargo, flying
parcels point to point on Emirates aircraft from and to the United Arab Emirates, Saudi Arabia,
Bahrain, Kuwait, Oman, Qatar, South Africa, the United Kingdom, Australia, Germany and India.
Its site is emiratescx.com.

## Numbers

Its tracking numbers are twelve digits. Many carriers print twelve digits and no public number
is known, so there is no rule.

## Why there is no adapter

The tracking page asks an open JSON service without a session, which gives empty fields for an
unknown number. No public number has shown a known parcel's reply yet. An adapter can follow.

## Links

Tracking links carry the number as `awb_number` on the tracking-details page.
