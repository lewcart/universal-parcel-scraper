# EMS Vietnam

EMS Vietnam parcels use enabled universal providers. There is no dedicated adapter.

EMS Vietnam (Tổng công ty Chuyển phát nhanh Bưu điện) is Vietnam Post's express company. It
runs its own tracker at ems.com.vn; `vnpost` covers the national post's own tracker.

## Numbers

EMS Vietnam items carry UPU S10 numbers ending in VN, as in the tracking page's own examples
and archived lookups. Generic postal detection already recognises them, so no rule names EMS
Vietnam.

## Links

`ems.com.vn/tra-cuu/tra-cuu-buu-gui?code={number}` is the address archived lookups on the
tracking page use.
