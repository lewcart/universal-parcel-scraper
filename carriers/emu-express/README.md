# EMU Express

EMU Express parcels use enabled universal providers. There is no dedicated adapter.

Express Mail Universal LLC of Tashkent, trading as EMU Express since 2016, delivers parcels and mail
across Uzbekistan from over two hundred branches, has branches in Kazakhstan and sends international
mail. Its site is emu.uz.

## Numbers

Its pages give no layout and no public number is known, so there is no rule.

## Why there is no adapter

The tracker asks an open JSON service with the number alone, without a login or CAPTCHA, and answers
an unknown number with a not-found reply. No public number has shown a known reply yet. An adapter
can follow.

## Links

Tracking links carry the number as `id` on `tracking` pages at emu.uz.
