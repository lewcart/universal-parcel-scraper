# Envía

Envía parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Envía guías are twelve digits; archived lookups on its own trackers show them starting with
a three-digit code such as `014`, `024`, `034` or `126`. Twelve digits are printed by many
carriers, so no rule claims them.

## Links

`envia.co/tracking` reads the guía from `?guia=`. The former tracker on `portal.envia.co`
read it from `?Guia=`, and the Envía Colvanes site from `?rastreo=` on `Contenido.aspx`.
