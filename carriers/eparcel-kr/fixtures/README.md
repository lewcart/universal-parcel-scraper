# Fixtures

Each file follows the English page `www.eparcel.kr/Track/Result?mode=0&ids={number}` answers,
with its scripts, menus and the heading naming the number. `not-found.html` is the page's answer
for a number it has no parcel for.

`in-transit.html` is a parcel for the Philippines up to its arrival there, with the Korean leg's
clocks marked local and Ninja Van named as the delivery company under eParcel's own number.
`delivered.html` is a parcel for Singapore through Janio's scans to the delivery, with the
details on one line as older pages print them. No found reply was seen live, so their history
and details follow archived pages of the tracker and a saved page an open-source tracker keeps
as a test fixture.

Numbers, senders, order numbers, airports, scan lines and days are invented.
