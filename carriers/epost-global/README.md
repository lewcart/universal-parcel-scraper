# ePost Global

ePost Global parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

ePost Global numbers are `EPG` and ten to thirteen digits. An Amazon seller's forum post lists
them, and `epost-global-1` claims the prefix.

## Links

ePost Global's tracker lives on `epgtrack.com` and posts the number, so no link opens one
parcel.

Provider live-test inputs and commands are in the [provider READMEs](../../providers/README.md).
