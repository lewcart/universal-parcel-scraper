# Equick

Equick parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Equick's own tracker showed nine-digit tracking numbers. Nine digits are a shape other
carriers share, so no rule claims them. Tracking sites also quote `EQK` numbers with a `YQ`
tail as Equick examples, but no Equick page shows that layout, so no rule claims it either.

## Links

The tracker at `www.equick.cn/#/support/supportWay` reads `nums` from the address fragment and
looks the numbers up at once; its copy-link button builds that address. The site answers on
HTTP only, so there is no search page and no URL template.
