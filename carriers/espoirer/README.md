# ESPOIRER

ESPOIRER parcels use enabled universal providers. There is no dedicated adapter.

ESPOIRER (株式会社エスポリア) clears and delivers cross-border online orders in Japan, AliExpress
parcels among them, as エスポ便. Its site is espoirer.com.

## Numbers

Guides describe its numbers as E and eleven digits, but only with made-up examples, so there is
no rule.

## Why there is no adapter

The tracking page asks an open JSON service without a session, which gives an empty list for an
unknown number. No public number has shown a known parcel's reply yet. An adapter can follow.

## Links

The tracking page takes numbers typed into its form; there are no tracking links.
