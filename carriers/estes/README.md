# Estes

Estes freight shipments use enabled universal providers. There is no dedicated adapter.

## Numbers

Estes PRO numbers are ten digits, as an aggregator page lists them. Estes publishes no check
digit, and ten digits are shared with several carriers, so no rule claims them.

## Links

The home page's tracking form sends a PRO number to
`estes-express.com/myestes/shipment-tracking/?type=PRO&query={number}`.
