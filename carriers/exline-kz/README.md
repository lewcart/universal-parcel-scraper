# Exline

Exline parcels use enabled universal providers. There is no dedicated adapter.

Exline is a Kazakh express courier delivering between the country's cities.

## Numbers

Its waybill numbers are ten digits, seen in its API documentation and in a customer review.
Ten-digit runs are printed by many carriers, so no rule claims them. The tracker's placeholder
shows an EMU prefix, but no real number of that layout has been seen.

## Links

The site's search action opens `exline.kz/<language>/tracking?id={number}`, which is read as a
link for the Russian, Kazakh, English and Uzbek pages.
