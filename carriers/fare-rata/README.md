# Fare Rata

Fare Rata parcels use enabled universal providers. There is no dedicated adapter.

Fare Rata (Fare Rata SAS), in Papeete, is French Polynesia's post. It is the postal company of
the Office des Postes et Télécommunications (OPT), which ran the post under its own name before.
Its site is farerata.pf.

## Numbers

Its help page names two layouts. UPU S10 numbers, ending `PF` for its own items, go to generic
postal detection. La Poste's layout, a digit, a letter and eleven digits, is the number under
which it delivers items from France, and stays with [La Poste](../la-poste/README.md). No rule
for Fare Rata claims either.

## Why there is no adapter

The tracking page in its customer area asks an open JSON service without a key, login or
CAPTCHA. No public number has shown a known item's reply yet. An adapter can follow.

## Links

The tracking page is an app that looks numbers up in place, so no address names one item.
