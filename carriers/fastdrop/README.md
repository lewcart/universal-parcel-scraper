# Fastdrop

Fastdrop parcels use enabled universal providers. There is no dedicated adapter.

Fastdrop is a Maltese parcel delivery service of the eCabs group.

## Numbers

An archived lookup on its tracker shows a ten-digit tracking ID with leading zeros. Ten bare
digits are shared with other carriers, so no rule claims them.

## Links

`booking.fastdrop.mt/package-tracking/{number}` opens one parcel. The search page at
tracking.fastdrop.mt builds that address.
