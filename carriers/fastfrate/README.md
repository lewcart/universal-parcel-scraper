# Fastfrate

Fastfrate parcels use enabled universal providers. There is no dedicated adapter.

Fastfrate is a Canadian less-than-truckload and intermodal freight carrier.

## Numbers

Fastfrate tracks a shipment by its probill number. Lookups archived from its own tracker
show ten digits. Ten digits are shared by many carriers, so no rule claims them.

## Links

The FastNet quick probill tracker opens one shipment from `ProbillNo` on `FastNet.aspx`,
on `apps.fastfrate.com` and formerly on `www.fastfrate.com`. The newer tracker takes the
number in a form and fetches it from its script, so it has no address of its own.
