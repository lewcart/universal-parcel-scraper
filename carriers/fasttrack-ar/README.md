# Fast Track

Fast Track parcels use enabled universal providers. There is no dedicated adapter.

Fast Track, the trading name of Servicios Logísticos Integrados S.R.L. in Avellaneda, Buenos
Aires, is an Argentine logistics company that delivers the last mile and carries courier imports
and exports. Its site is fasttrack.com.ar.

## Numbers

No public page shows one of its tracking codes, so there is no rule.

## Why there is no adapter

Its tracking page asks one of two JSON services on its own site, for national or international
shipments, without a session or CAPTCHA. No public code has shown a known parcel's reply yet. An
adapter can follow.

## Links

The tracking page looks codes up in place, so no address names one.
