# Fixtures

Each fixture follows Fermopoint's booking page for one code, `/prenotazione/{code}`, trimmed to
the heading, the steps and the sign-in prompt, as the page writes them.

`delivered.html` is a Fermoticket collected at its shop, with a step in the hour Rome's clocks
repeat and two steps of the same second. `in-transit.html` is a Fermoticket on its way to the
shop. `shipment.html` is a parcel sent from a shop and collected by its recipient.
`not-found.html` is the page's notice for a code it holds no active booking for.

Codes and clocks are invented.
