# Fmile

Fmile parcels use enabled universal providers. There is no dedicated adapter.

Fmile, based in the Los Angeles area, delivers large and oversized parcels over the last mile in the
United States, many of them cross-border online orders, and hands some to FedEx for the last leg.
Its site is fimile.com.

## Numbers

No public page shows one of its numbers or states their layout, so there is no rule. Parcels handed
to FedEx also carry a FedEx number, which FedEx's rules read.

## Why there is no adapter

The tracker asks an open JSON service without a session, which answers an unknown number with an
empty list rather than an error. No public number has shown a known parcel's reply yet. An adapter
can follow.

## Links

Tracking links carry the number as `trackingNumber` on the tracking page.
