# First Delivery

First Delivery parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

First Delivery is a Tunisian express delivery company. Its waybill numbers, which it calls
barcodes, are twelve digits; its merchant API documentation states the length and shows real
ones in its examples. No rule claims them, because twelve bare digits are shared with many
other carriers.

## Links

The tracking page on firstdeliverygroup.com takes a waybill number in a form and has no
address that opens one parcel, so no link is read.
