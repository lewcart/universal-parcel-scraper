# First Fly Express

First Fly Express parcels use enabled universal providers. There is no dedicated adapter.

First Fly Express is a domestic courier in India that hands international shipments to global
networks.

## Numbers

The tracker takes consignment numbers. Its own example shows a nine-digit number. Nine-digit
runs are printed by many other carriers, so no rule claims them.

## Links

The tracker posts its form to `track.asp`, so no address opens one parcel.
