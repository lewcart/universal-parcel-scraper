# Fixtures

The pages follow the tracking page `track.fleetopticsinc.com/?tracking_number={number}` renders,
cut down to the search form, the summary and the tracking history, newest first.
`delivered.html` is an Eastern parcel delivered after a missed visit, with one row listed twice,
the recipient's postal code in a script and proof-of-delivery photos. `in-transit.html` is a
Pacific parcel at a transfer terminal with a weekday estimate, and `out-for-delivery.html` an
Eastern one with today's delivery window. `not-found.html` is the notice for a number the
tracker does not hold.

Numbers, places, postal codes, links and clocks are invented.
