# FMD Distribution

FMD Distribution parcels use enabled universal providers. There is no dedicated adapter.

FMD Distribution is a warehousing and freight company in Kearny, New Jersey, with a terminal in Glen
Burnie, Maryland. It runs truckload, less-than-truckload and white-glove delivery in the Northeast and
Mid-Atlantic. Its site is fmddistribution.com.

## Numbers

No public page shows one of its PRO numbers, so there is no rule.

## Why there is no adapter

Its tracker is hosted by Carrier Logistics, whose open XML trace
[Dohrn Transfer](../dohrn-transfer/README.md)'s adapter reads, but no public PRO number has been
found to check a found reply with.

## Links

The tracker's shipment page opens a PRO number from its `wpro1` parameter, and its entry page
from `pronum`.
