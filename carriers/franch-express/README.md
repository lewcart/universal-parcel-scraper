# Franch Express

Franch Express parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Franch Express air waybill numbers are eleven digits. Customers quote them in complaints about
the courier, and an archived lookup on its tracker carries one. No rule claims them: many
carriers print eleven-digit numbers.

## Links

Franch Express's tracking form sends the number with a captcha, so no address opens one parcel.
Links to its older tracker carry the number in `keyword`.
