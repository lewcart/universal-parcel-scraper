# The FRONTdoor Collective

The FRONTdoor Collective parcels use enabled universal providers. There is no dedicated adapter.

The Frontdoor Collective LLC, in Brentwood, Tennessee, is a franchise network of local last-mile
delivery operators in the United States, which deliver parcels under its own tracking numbers. Its
site is frontdoorcorp.com.

## Numbers

No public page shows one of its numbers or states their layout, so there is no rule.

## Why there is no adapter

The status page asks an open JSON service without a login, which answers an unknown number with an
error. Proof of delivery needs the recipient's last name and ZIP code. No public number has shown a
known parcel's reply yet. An adapter can follow.

## Links

Tracking links carry the number as `etid` on the app's status page.
