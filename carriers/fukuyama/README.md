# Fukuyama Transporting

Fukuyama Transporting parcels use enabled universal providers. There is no dedicated adapter.

Fukuyama Transporting (福山通運) is a Japanese parcel and freight carrier.

## Numbers

The tracking number (お問い合わせ番号) has ten or eleven digits. In the eleven-digit numbers the
last digit is the rest modulo 7, the same check as Japan Post's registered numbers, so neither
length tells Fukuyama apart and no rule claims them.

## Links

`corp.fukutsu.co.jp/situation/tracking_no_hunt/{number}` opens one parcel.
