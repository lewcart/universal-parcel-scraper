# Furniture Logis

Furniture Logis parcels use enabled universal providers. There is no dedicated adapter.

Furniture Logis, S.L., based in Arganda del Rey near Madrid, delivers and assembles furniture at
home for online shops and retailers across mainland Spain and in Palma de Mallorca, from warehouses
around the country, and takes old furniture away for recycling. Its site is furniturelogis.es.

## Numbers

Its tracker takes an order file number, a delivery note number or a tracking reference of up to
thirty characters. No public page shows one, so there is no rule.

## Why there is no adapter

The tracker shows a page of its routing system that also asks for the recipient's phone number and
postcode, and answers an unknown reference as missing or incomplete. No public reference has shown
whether the reference alone finds an order.

## Links

The tracker's address can carry the phone number and postcode too, and no public reference shows
whether it opens an order without them, so there are no tracking links.
