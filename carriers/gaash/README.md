# GAASH Worldwide

GAASH Worldwide parcels use enabled universal providers. There is no dedicated adapter.

GAASH Worldwide is an Israeli e-commerce import line. It flies online orders to Israel and
clears them through customs. Its tracker at gaashwd.com follows the parcel under GAASH's number
and then names the company that delivers it: HFD, Mailog or Chita. Mailog's own tracking page
embeds the same tracker.

## Numbers

Archived lookups on the tracker show three layouts: `GWD` and nine digits, `GAIH` and eight
digits, and `PH` and ten digits, which the tracker also gives as the HAWB. Only one lookup of
each is archived, so no rule claims them. Purolator's three-letter rule claims the `GWD`
layout; the other two get only weak suggestions from other carriers.

## Links

`gaashwd.com/track-parcel/?TrackingNumber={number}` opens the tracker on one parcel: its script
reads `TrackingNumber`. Archived lookups pass the same parameter to the home page and to the
Hebrew tracker page.
