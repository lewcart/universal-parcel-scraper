# Gebrüder Weiss

Gebrüder Weiss shipments use enabled universal providers. There is no dedicated adapter.

## Numbers

An integration vendor's help article gives a Gebrüder Weiss number of two letters, five digits,
a hyphen and eight digits. One sample does not establish a rule.

## Links

Gebrüder Weiss's public Track & Trace on `my.gw-world.com` reads no number from its address,
so no link opens one shipment.
