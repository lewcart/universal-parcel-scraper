# Geniki Taxydromiki

Geniki Taxydromiki parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

A Trustpilot review gives a ten-digit Geniki Taxydromiki parcel number. Ten digits are
shared with several carriers, so no rule claims them.

## Links

Geniki Taxydromiki's tracker opens a number at `taxydromiki.com/track/{number}`.

## Testing

Provider live-test inputs and commands are in the [provider READMEs](../../providers/README.md).
