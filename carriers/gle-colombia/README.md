# G.L.E.

G.L.E. parcels use enabled universal providers. There is no dedicated adapter.

G.L.E. (Grupo Logístico Especializado S.A.S.), in Bogotá, is a Colombian logistics company that
carries parcels, documents and bulk loads across the country for corporate customers, alongside
e-commerce and international shipping. Its site is glecolombia.com.

## Numbers

Its guide numbers are digits. The one public guide, in a search engine's copy of its tracker's page,
has eleven digits, and the tracker no longer finds it. Eleven digits are a shape many carriers
share, so no rule claims it.

## Why there is no adapter

The tracker is a plain page that reads the guide number from its address, without a session or
CAPTCHA, and says when it does not find a guide. No public guide it still knows has been found. An
adapter can follow.

## Links

Tracking links carry the guide number as `guia` on the guide details page of its aGiLE platform.
