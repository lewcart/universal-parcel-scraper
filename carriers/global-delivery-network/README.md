# Global Delivery Network

Global Delivery Network parcels use enabled universal providers. There is no dedicated adapter.

Global Delivery Network (GDN), based in Kentucky, sends mail and online orders from the United
States abroad, clears them through customs and hands them to carriers there, such as DHL and NZ
Post. Its site is gdnparcel.com.

## Numbers

Its tracker shows twelve-digit numbers. Many carriers print twelve digits, so there is no rule.

## Why there is no adapter

The tracker is a plain page that lists a parcel's scans without a session, and the hand-off
scan names the carrier that delivers. Its scans give no time zone, and a single public number has
been found. An adapter can follow.

## Links

Tracking links carry the number as `track` on the tracker.
