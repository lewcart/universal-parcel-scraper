# GLS Spain

GLS Spain parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

GLS Spain numbers in public OCU complaints are ten digits starting `1`. GLS publishes no
length or check-digit rule, and ten digits are shared with several carriers, so no rule
claims them and the user picks GLS Spain.

## Links

GLS Spain's tracking form sends a domestic shipment number to
`mygls.gls-spain.es/e/?codigo={number}`. International parcels go to the group tracker with
`?match=`.
