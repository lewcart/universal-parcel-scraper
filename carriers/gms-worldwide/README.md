# GMS Worldwide Express

GMS Worldwide Express parcels use enabled universal providers. There is no dedicated
adapter.

GMS Worldwide Express is a domestic courier network based in Bengaluru, India, with regional
offices, branches and franchisees across the country.

## Numbers

Complaints give nine-digit consignment numbers. Nine digits are printed by many carriers, so
no rule claims them.

## Links

The tracking form on the home page opens `/shipment-tracking` with the number as
`tracking_no` and the lookup type as `tracking_type`.
