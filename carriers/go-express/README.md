# GO! Express

GO! Express parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Lookups archived from GO!'s tracker, on its German and Danish pages, show twelve-digit numbers.
GO! publishes no layout or check digit, and twelve digits are shared with FedEx, GLS and many
other carriers, so no rule claims them and the user picks GO! Express.

## Links

GO!'s tracking pages on `www.general-overnight.com`, one per country and language, take the
number as `reference`. The German page's own permalink opens one shipment at
`/deu_de/versenden/sendungsverfolgung.html?reference={number}`, and archived lookups used the
same parameter on the former `/deu_de/sendungsverfolgung.html` and on the Danish English page.
