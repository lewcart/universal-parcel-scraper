Synthetic pages in the shape of GO Logistics' tracker: `delivered.html` is a consignment booked, collected and
delivered, with the signatory and a signature image; `reused.html` lists an earlier consignment under the same
number before the current one; `not-found.html` is the heading alone, the page for a number with no scan.
Numbers, drivers, the signatory, the signature and clocks are invented.
