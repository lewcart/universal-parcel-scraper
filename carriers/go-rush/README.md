# Go Rush

Go Rush parcels use enabled universal providers. There is no dedicated adapter.

Go Rush, also Go Rush Express, is based in Bandar Seri Begawan. It delivers parcels and runs errands
across Brunei, and sends parcels abroad. Its site is gorushbn.com.

## Numbers

The example in its tracking box reads GR and nine digits, but it is made up and no public number is
known, so there is no rule.

## Why there is no adapter

The tracking box on its home page asks an open JSON service without a session, which answers an
unknown number with not found. No public number has shown a known parcel's reply yet. An adapter can
follow.

## Links

The tracking box looks numbers up in place, so there are no tracking links.
