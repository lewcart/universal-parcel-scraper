# Go World Express

Go World Express parcels use enabled universal providers. There is no dedicated adapter.

Go World Express (行界物流), based in Shenzhen, runs small-parcel lines from China, one of them to Brazil, and
resells postal and international express services. Its site is goworldexpress.cn.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

Its waybill query is a page of a hosted forwarding system served on its own site and takes several numbers
without a login. No public number is known to see a found reply.

## Links

Its waybill query looks numbers up in place, so no address names one.
