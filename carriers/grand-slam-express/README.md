# Grand Slam Express

Grand Slam Express parcels use enabled universal providers. There is no dedicated adapter.

Grand Slam Express is a Mumbai-based express courier and logistics company in India.

## Numbers

The tracker takes AWB numbers. A lookup archived from it carries a nine-digit AWB number.
Nine-digit runs are printed by many other carriers, so no rule claims them.

## Links

The tracker script reads `AwbNo` from the address of `Web/Track` and looks the number up at
once, so that address opens one parcel and the number is read from it.
