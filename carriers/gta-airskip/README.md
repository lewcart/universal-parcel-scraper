# GTA AirSkip

GTA AirSkip parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

GTA AirSkip, formerly GTA GSM, is a Mississauga air freight and e-commerce delivery company.
Archived lookups on its tracker show numbers of 19 letters and digits: GRG for its Ground
service or GRS for its Select service, five digits, then eleven letters or digits.

A low-confidence rule offers GTA AirSkip for that shape. Intelcom's tracker also returns
history for one such number, so the rule does not name GTA AirSkip on its own.

## Links

One parcel opens on gtaairskip.com, or on the former gtagsm.com, under `/tracking/` with an
optional language prefix and the number in the `trackingid` or `tracking` parameter. The
tracker reads either parameter when the page loads, and the library reads the number from
either.
