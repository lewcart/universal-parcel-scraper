Synthetic replies of the Hualei platform's track interface (`track.json`, `no-track.json`) and
tracking page (`page.html`, `page-unknown.html`), shared by the platform tests. `track.json`
holds a timeline written in one go before the parcel moved, whose last row is ahead of the tests'
read time; `page.html` writes a postcode and a signatory into a row. Numbers, references, parties,
places and clocks are invented. The interface's replies are GBK; the files are UTF-8.
