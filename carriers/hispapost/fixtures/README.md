# Fixtures

The pages of `https://intranet.hispapost.es/tracking`, kept as the tracker serves them.
`page.html` is the empty form with its token. `delivered.html` is the answer for a Joom
number delivered on a March day; `returned.html` for a Temu number sent back after nobody
collected it, set during the hour Madrid's clocks repeat in October. `in-transit.html`
carries a wording no reply showed, to exercise the shared wording rules. `not-found.html` is
the HTTP 422 answer: the form again, with the flash message naming the barcode.

Numbers, tokens and clocks are invented.
