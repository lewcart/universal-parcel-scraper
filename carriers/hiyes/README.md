# Hiyes

Hiyes parcels use enabled universal providers. There is no dedicated adapter.

Hiyes (新航通運), run by 新航通運有限公司 (Hiyes Logistics Corporation) in Wugu, New Taipei, carries
and stores goods across Taiwan for business customers: warehousing and order picking, express and
home delivery, container transport and delivery to the outlying islands. Its site is
hiyes.com.tw.

## Numbers

Its tracker takes complete consignment note numbers (托運單號), letters in their exact case, up to
ten at a time. No public page shows one or states their layout, so there is no rule.

## Why there is no adapter

The tracking page puts the numbers, separated by slashes, in the address of a detail page on the
same site. That page sends a number it does not know back to the home page. No public number has
shown a known parcel's reply yet.

## Links

No known parcel has shown that the detail page opens it from its address, so there are no
tracking links.
