# HOMEXPRESS

HOMEXPRESS parcels use enabled universal providers. There is no dedicated adapter.

HOMEXPRESS is a Sydney courier that delivers e-commerce parcels, such as SHEIN orders, to homes
in Australian cities with its own drivers. Its tracker runs on the same software as EWE Group's
second tracker.

## Numbers

No public source shows a whole HOMEXPRESS number, so the corpus is empty and no rule claims a
layout.

## Links

The tracker looks the number up from its search field and reads none from its address, so no
link opens one parcel.
