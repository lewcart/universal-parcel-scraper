# HAL Express

HAL Express parcels use enabled universal providers. There is no dedicated adapter.

HAL Express, the express service of Houng Ah Loun Logistics, carries parcels between its
branches in Laos and to the border with neighbouring countries.

## Numbers

The bill number starts with the sending branch's three-letter code followed by eleven digits,
as the example in the carrier's own web app shows. No rule claims it: the layout rests on that
one example, and Lao carriers print similar branch-coded bills.

## Links

`halexpress.la/parcel/` followed by the bill number opens one parcel; the carrier's web app
builds this address when it shares a parcel.
