# Fixtures

Each file follows the page `www.hovership.com/track/{number}/` answers, with the site's menus and
footer cut short and its styles and icons left out.

`delivered.html` is a parcel from its label to its delivery at the door, with its headline,
progress rail, history newest first, the ZIP code form and the origin and destination towns.
`in-transit.html` is a parcel scanned in at a sort facility, headed by its latest delivery time,
in winter time. `not-found.html` is the page's HTTP 404 answer for a number it has no shipment
for.

Numbers, towns, facilities and clocks are invented.
