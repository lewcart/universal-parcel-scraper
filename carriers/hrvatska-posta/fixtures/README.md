# Fixtures

`locker.html`, `returned.html` and `abroad.html` follow the shape of the English page of
Hrvatska pošta's tracker: the number, the weight, the delivering unit's logo and the scans
under the page's milestones, each in a desktop and a mobile row. Numbers, offices, lockers,
facilities and clocks are invented. `not-found.html` is the page for a number without data,
`invalid.html` the page for a number the tracker does not accept and `error.html` the error
page the site can serve for a known item.
