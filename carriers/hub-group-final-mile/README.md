# Hub Group Final Mile

Hub Group Final Mile parcels use enabled universal providers. There is no dedicated adapter.

Hub Group Final Mile, formerly NonstopDelivery (NSD) of Chantilly, Virginia, which Hub Group bought
at the end of 2020, delivers large and bulky items to homes across the United States. Its pages are
on hubgroup.com.

## Numbers

Its numbers are short counters of seven or eight characters, shapes many other networks print, so
there is no rule.

## Why there is no adapter

Its tracker needs the delivery ZIP code with the number, and it blocks automated requests.

## Links

Links to tracking.shipnsd.com carry the number as `t` next to the ZIP code; only the number is read
from them.
