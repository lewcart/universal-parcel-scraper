# HZT International Logistics

HZT International Logistics parcels use enabled universal providers. There is no dedicated adapter.

HZT International Logistics (豪泽通国际物流), based in Shenzhen, runs small-parcel lines from China to the
United Kingdom, the United States, Canada and Europe. Its site is hztgjwl.com.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

Its waybill query looks a number up through its own API without a login. No public number is known to see a
found reply.

## Links

Its waybill query looks numbers up in place, so no address names one.
