# ICC Worldwide

ICC Worldwide parcels use enabled universal providers. There is no dedicated adapter.

ICC Worldwide is an international courier serving India since the 1970s, with a network in the
US and Europe. It carries cross-border e-commerce and shop-abroad orders into India.

## Numbers

ICC air waybills are plain digit runs; the one public number found has eleven digits. No rule
claims them, since many carriers print digit runs of that length.

## Links

ICC's track form opens one air waybill at `www.iccworld.com/track-result.php?track_no=`
followed by the number. Its older tracker used `track.asp?txtawbno=`.
