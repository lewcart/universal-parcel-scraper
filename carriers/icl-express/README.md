# ICL Express

ICL Express parcels use enabled universal providers. There is no dedicated adapter.

ICL Integrated Couriers & Logistics is a courier based in Hyderabad, India. It also books
international shipments that a partner such as FedEx delivers abroad.

## Numbers

Lookups archived from ICL's former tracker show ten-digit waybills, with ICL's own scans
followed by the partner's under a separate forwarding number. Ten digits are printed by many
carriers, so no rule claims them. A lettered number from the same tracker has the shape of
DTDC's waybills and is kept for review.

## Links

The current tracker on `iclexpress.in` reads the number from its form and calls its
tracking APIs, so no address opens one parcel there. The former tracker on
`iclinternational.in` took the number as `txtawbno` on `Tracking.aspx`.
