# Ilyang Logis

Ilyang Logis parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Ilyang Logis, formerly 일양택배, prints bare digit waybill numbers. Archived lookups on its
former tracker show nine-digit numbers, and its current lookup takes up to ten characters.
Many Korean carriers print the same digit runs, so no rule claims them.

## Links

The tracking page on `ilyanglogis.co.kr/page/Tracking.do` opens
`ilyanglogis.co.kr/page/TrackingResult.do?trackingType=0&blNum={number}`, which shows one
parcel. The former tracker on `ilyanglogis.com` read the number from `hawb_no` on its
`functionality` result pages.
