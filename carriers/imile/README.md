# iMile

iMile parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

iMile delivers cross-border e-commerce parcels in the Middle East, Latin America, Europe and
Australia. Its own waybill numbers are thirteen digits, seen in archived lookups on its
trackers for several countries. Thirteen digits are a bare counter many carriers share, so no
rule claims them. iMile's tracker also accepts marketplace references with CNBR and AP
prefixes, which belong to the sender's logistics partner, so they are not claimed either.

## Links

The tracker on `imile.com` opens one parcel at `/<country>-<language>/track` with the number in
`?waybillNo=`. The form on the English page builds that address.
