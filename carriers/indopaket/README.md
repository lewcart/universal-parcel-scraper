# Indopaket

Indopaket parcels use enabled universal providers. There is no dedicated adapter.

Indopaket, run by PT Inti Paket Prima of the Indomaret group, takes parcels at Indomaret stores
across Indonesia and delivers them to other stores or to addresses. Its site is indopaket.co.id.

## Numbers

The store or Indopaket's app gives each parcel a receipt (resi) number. No public page shows one,
and the tracker's placeholder is made up, so there is no rule.

## Why there is no adapter

Every lookup sends a reCAPTCHA Enterprise token.

## Links

The tracker takes numbers typed into its form; there are no tracking links.
