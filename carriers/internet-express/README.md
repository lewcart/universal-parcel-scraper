# Internet Express

Internet Express parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Internet Express tracks shipments on a Ship Logic portal. An archived lookup on its tracking
API shows a nine-character reference of letters and digits; the reply also lists a
six-character short reference and, per parcel, the reference followed by `/1`. No rule claims
these references: their shape has nothing that points to Internet Express.

## Links

The portal opens one shipment at `portal.internetexpress.co.za/track?ref={number}`, the address
of the archived lookup. The waybill form on the home page posts the number instead.
