# Inter Rapidísimo

Inter Rapidísimo parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Inter Rapidísimo tracks a shipment by its guide number (número de guía), which its home page
tracking field accepts as twelve or thirteen digits. Bare digit runs of these lengths are
printed by many carriers and nothing in the number points to Inter Rapidísimo, so no rule
claims them.

## Links

The page `interrapidisimo.com/sigue-tu-envio/?guia=` followed by the number opens a shipment.
`siguetuenvio.interrapidisimo.com/` followed by the number, the older
`interrapidisimo.com/ExploradorEnvios/Views/?guia=` page and the first tracker on
`www3.interrapidisimo.com` with `tbxNumeroGuia` also name the guide.
