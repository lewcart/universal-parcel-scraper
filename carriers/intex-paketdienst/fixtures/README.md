# Fixtures

`delivered.html` and `in-transit.html` follow the page INTEX's tracker renders for a shipment, as
an archived lookup shows it: the number and the destination, then the scans, oldest first, and
the hidden link to a partner's tracker. `delivered.html` is a winter shipment with two arrival
scans at the hub a minute apart and a delivery row; no delivered page has been seen, so that
row's wording is a plausible one. `in-transit.html` is a summer shipment at its delivery station.
`not-found.html` is the page for a number the tracker does not know.

Numbers, partner numbers, postcodes, towns and clocks are invented.
