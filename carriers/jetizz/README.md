# Jetizz

Jetizz parcels use enabled universal providers. There is no dedicated adapter.

Jetizz Hızlı Taşımacılık A.Ş., based in Beykoz, Istanbul, delivers online shops' orders across Turkey. Its site is jetizz.com.

## Numbers

Its numbers are counters of ten or thirteen digits whose leading digits rise over time, shapes many
other networks print, so there is no rule.

## Why there is no adapter

Its tracker asks for an image CAPTCHA with every lookup.

## Links

The tracker has no per-shipment address, so there are no tracking links.
