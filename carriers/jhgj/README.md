# Jiuhao International

Jiuhao International parcels use enabled universal providers. There is no dedicated adapter.

Jiuhao International (广州九好国际货运代理有限公司, JHGJ) is a Guangzhou freight forwarder.
Its website does not answer, and no copy of it is archived.
