# Jiachen International Express

Jiachen International Express parcels use enabled universal providers. There is no dedicated adapter.

Jiachen International Express (佳辰国际速递), based in Fremont, California, ships parcels from the United
States to China. Its site is jiachenexpress.com.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

Its waybill query is a page of a hosted forwarding system that looks a waybill number up without a login or
CAPTCHA. No public number is known to see a found reply.

## Links

Tracking links carry the number as `num` on its `select.html` page.
