# Jiaying Express

Jiaying Express parcels use enabled universal providers. There is no dedicated adapter.

Guangzhou Jiaying International Logistics (广州佳赢国际物流) runs cleared road, air, sea and express
lines from China to Russia and Kazakhstan, and lines to Southeast Asia. Its site is jiayingex.com.

## Numbers

No public number or stated layout is known, so there is no rule.

## Why there is no adapter

Its tracker answers only over plain HTTP, on a bare IP address.

## Links

The tracker has no per-shipment address, so there are no tracking links.
