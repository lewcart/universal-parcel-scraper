# Jikuaida Logistics

Jikuaida Logistics parcels use enabled universal providers. There is no dedicated adapter.

Jikuaida Logistics (吉快达物流), based in Changsha, Hunan, runs cross-border e-commerce shipping and truckload
and less-than-truckload freight within China. Its site is jikuaida.com.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

Its tracking page reads the numbers from the address and shows the scans without a login. No public number
is known to see a found reply.

## Links

Tracking links carry the number as `nums` on its `track.html` page.
