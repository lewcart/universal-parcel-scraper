# Jitsu

Jitsu parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

A Trustpilot review gives a Jitsu tracking code of sixteen lower-case letters and digits.
One sample does not establish a rule.

## Links

Jitsu's recipient app opens a parcel at `recipient.gojitsu.com/{code}`; the former
`recipient.axlehire.com` host still resolves there.

## Testing

Provider live-test inputs and commands are in the [provider READMEs](../../providers/README.md).
