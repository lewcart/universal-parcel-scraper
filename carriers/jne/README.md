# JNE

JNE (Jalur Nugraha Ekakurir) parcels use enabled universal providers. There is no dedicated
adapter.

## Numbers

JNE resi numbers seen in complaints are fifteen or sixteen digits, which many carriers share,
so no rule claims them. JNE Trucking (JTR) consignments are `JT` and eleven digits; `jne-1`
claims them, a shape only La Poste's broad two-character rule also takes.

## Links

JNE's tracking form posts the number with a session token, so no address opens one parcel.
