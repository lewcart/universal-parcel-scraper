# Jordan Post

Jordan Post parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Jordan Post tracks UPU S10 numbers, which postal detection handles.

## Links

The tracker lives on an IP address that Jordan Post's own tracking page embeds. Its result page
opens one item from `Result.aspx?itemid={number}`; the library reads the number from it.
