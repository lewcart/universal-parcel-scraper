# Kerry TJ

Kerry TJ parcels use enabled universal providers. There is no dedicated adapter.

Kerry TJ Logistics (嘉里大榮物流) is a Taiwanese freight and parcel carrier in the Kerry Logistics
group. It is a different network from KEX Express in Thailand and Hong Kong.

## Numbers

Archived lookups show eleven-digit consignment numbers (託運編號). No rule claims them: bare
eleven-digit numbers are printed by many carriers.

## Links

`kerrytj.com/webquery/CargoStatus/CS_Search_KtjNo.aspx?ktjNO={number}` opened one
consignment in archived lookups. The current site has a lookup page without a known address
that carries the number.
