# KEX Express Hong Kong

KEX Express Hong Kong parcels use enabled universal providers. There is no dedicated adapter.

KEX Express (Hong Kong) is the Kerry Logistics Network's local express carrier, formerly Kerry
Express Hong Kong. It has its own site and tracker, separate from KEX Express in Thailand
(`kex`).

## Numbers

Archived lookups show a letter followed by nine digits and, under the former name, a
fourteen-character number starting with KEHK. No rule claims them: the first shape is printed
by other carriers, and the second rests on a single sample.

## Links

`kex.kln.com/{en|zh}/track?track={number}` opens one parcel; the tracker's own form submits
there. The former `hk.kerryexpress.com/track` and `/en/track` addresses used the same
parameter.
