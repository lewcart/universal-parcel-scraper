# Fixtures

The pages follow the tracker's page for one number, without the PHP warnings the server prints
in an HTML comment before each page. `delivered.html` lists a delivered parcel newest first,
with one sortation scan twice in the same half-day as the tracker shows it. `in-transit.html`
has reached the sortation hub. `not-found.html` is the tracker's answer to a number it has no
record of.

Numbers, days and the Imperva script's parameters are invented.
