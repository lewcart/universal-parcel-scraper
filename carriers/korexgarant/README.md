# Korexgarant

Korexgarant parcels use enabled universal providers. There is no dedicated adapter.

Korexgarant (ООО «КОРЭКСГАРАНТ») of Minsk, in business since 1999, is an express courier for
documents and parcels within Belarus and to Russia, the CIS and the Baltic states, and for documents
worldwide. Its site is korex.by.

## Numbers

Its pages give no layout and no public number is known, so there is no rule.

## Why there is no adapter

The tracker on its site asks an open JSON service with the number alone, without a login or CAPTCHA,
and answers an unknown number with a not-found reply. No public number has shown a known reply yet.
An adapter can follow.

## Links

The tracker has no per-shipment address, so there are no tracking links.
