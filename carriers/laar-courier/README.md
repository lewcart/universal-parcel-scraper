# Laar Courier

Laar Courier parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

The Laar guía seen on its own tracker is three letters followed by ten digits. Only one public
guía is known, so the range of letter prefixes is unclear and no rule claims the layout.

## Links

`fenix.laarcourier.com/Tracking/` reads the guía from `?guia=` and writes it back there after a
search. The former tracker read it from `?Guia=` on `Tracking/Guiacompleta.aspx`.
