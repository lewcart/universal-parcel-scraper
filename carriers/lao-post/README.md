# Lao Post

Lao Post parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Lao Post prints UPU S10 numbers ending in `LA`; archived lookups on another post's tracker show
registered items accepted at Lao Post's office of exchange in Vientiane. Generic postal
detection handles S10 numbers, so Lao Post has no rule of its own.

## Links

The tracking page reads the number from its `tracking-number` parameter, which its search
button sets, and runs the lookup once the visitor completes its reCAPTCHA check.
