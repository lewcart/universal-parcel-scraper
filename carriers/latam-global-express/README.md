# Latam Global Express

Latam Global Express parcels use enabled universal providers. There is no dedicated adapter.

Latam Global Express, based in Miami, ships online orders from the United States to Latin America,
clears them through customs and hands them to local partners; its tracker covers Guatemala and
Honduras. It is not LATAM Airlines' cargo arm. Its site is latamglobalexpress.com.

## Numbers

Its tracker gives no layout or example, and no public number is known, so there is no rule.

## Why there is no adapter

The tracker is a plain page without a login or CAPTCHA that says when it does not find a number, but
every lookup needs the destination country, Guatemala or Honduras, as well as the number. No public
number has shown a known shipment's reply yet.

## Links

Lookups need the destination country, so there are no tracking links.
