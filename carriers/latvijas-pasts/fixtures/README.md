# Fixtures

`collected.json` and `abroad.json` follow the shape of the tracking service's English reply:
the scans newest first, each with a clock, an event code, its wording, the tracker's progress
group and either the Latvian office or, for a foreign post's event, the country. Offices, codes
of offices and clocks are invented. `collected.json` is an item from abroad collected from a
customer centre, `abroad.json` one sent abroad and delivered there. `not-found.json` is the
notice for a code without history.
