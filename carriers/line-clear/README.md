# Line Clear Express

Line Clear Express parcels use enabled universal providers. There is no dedicated adapter.

Line Clear Express is a Malaysian courier with its own branch and hub network.

## Numbers

Line Clear's former tracking form gave W followed by thirteen digits as its example. No rule
claims that layout: a single letter and digits do not point to Line Clear alone. Aggregators
describe current numbers as ZND followed by twelve digits, but no Line Clear source shows that
layout yet.

## Links

None. The tracker posts the number in a request body, so no address opens one parcel.
