# Logista Parcel

Logista Parcel parcels use enabled universal providers. There is no dedicated adapter.

Logista Parcel, formerly Integra2, is Grupo Logista's parcel network in Spain, Portugal and Andorra,
run by Dronas 2002, S.L. in Sant Andreu de la Barca near Barcelona. It carries
temperature-controlled parcels for pharmacies, food and industry. Its site is logistaparcel.com.

## Numbers

Its tracker takes a consignment or reference number of three to fifteen characters. No public page
shows one, so there is no rule.

## Why there is no adapter

The tracker asks an open JSON service, but every lookup needs the first three digits of the
destination postcode as well as the number.

## Links

Every lookup needs the postcode digits, so there are no tracking links.
