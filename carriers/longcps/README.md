# LONGCPS

LONGCPS parcels use enabled universal providers. There is no dedicated adapter.

LONGCPS (龙行速运), based in North York, Ontario, ships parcels from Canada to China. Its site is longcps.com.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

Its waybill query is a page of a hosted forwarding system that looks a waybill number up without a login or
CAPTCHA. No public number is known to see a found reply.

## Links

Tracking links carry the number as `num` on its `select.html` page when `type` is `cnum`; the same page
also looks up a phone number.
