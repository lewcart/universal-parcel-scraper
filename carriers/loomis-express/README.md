# Loomis Express

Loomis Express parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Loomis Express waybills are `NET` or `LSHP` and eight digits. Aggregator pages print both, and
`loomis-express-1` and `loomis-express-2` claim them. A door-knocker card number starting `DNK`
is not a waybill and is quarantined.

## Links

Loomis Express's tracker posts the waybill, so no link opens one parcel.
