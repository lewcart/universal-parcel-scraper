# LTL KR

LTL KR parcels use enabled universal providers. There is no dedicated adapter.

LTL (엘티엘) is a Korean forwarding and buying-agent service that gathers orders at its warehouse in
Weihai, China, and ships them to Korea, where a Korean courier delivers them. Its site is ltl.kr.

## Numbers

Its numbers start with L and run to eight to sixteen characters, a shape too broad for a rule, and
no public number is known.

## Why there is no adapter

Its tracker asks an open JSON service with a key the page gives every visitor, without a login or
CAPTCHA. No public number has shown a known reply yet. An adapter can follow.

## Links

The tracker has no per-shipment address, so there are no tracking links.
