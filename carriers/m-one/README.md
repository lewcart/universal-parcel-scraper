# M-ONE

M-ONE parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

M-ONE, the parcel courier of the Milšped group, tracks parcels under numbers in the UPU S10
layout with Serbia's country code; archived replies of its own tracking API show them. Postal
detection reads these numbers, so no M-ONE rule claims them. The tracker's fallback reply shows
the letters RS followed by twelve digits; one example does not establish a layout, so that
shape stays unclaimed.

## Links

The home page reads a number from its bare query string and opens that parcel's history.
