# MailPlus

MailPlus parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

MailPlus's tracker gives `MPX` and nine digits as its example tracking ID; `mailplus-au-1`
suggests MailPlus for that layout with low confidence, since only that example is public. The
tracker also takes the numbers of the carriers MailPlus lodges with, such as Australia Post,
which stay with those carriers' rules.

## Links

The tracker at `track.mailplus.com.au` opens one parcel at `/old/{number}` after a search.
