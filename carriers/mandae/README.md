# Mandaê

Mandaê parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Mandaê, also branded Nuvem Envio/Mandaê, ships e-commerce parcels through partner carriers and
tracks them on Rastreaê under its own code. The code is a four- or five-letter store prefix
followed by the store's item number, six to nine digits; older lookups also used a bare number.
The prefix belongs to the store, not to Mandaê, and the shapes are shared with other carriers'
references, so no rule claims them.

## Links

Rastreaê opens one parcel at `rastreae.com.br/resultado/{number}`. The former tracker used
`app.mandae.com.br/rastreamento/{number}`.
