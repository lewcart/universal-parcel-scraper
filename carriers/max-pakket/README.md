# MAX Pakket

MAX Pakket parcels use enabled universal providers. There is no dedicated adapter.

MAX Pakket, in Deventer, collects and delivers big, long and heavy parcels across the
Netherlands for businesses and individuals. Its site is maxpakket.nl.

## Numbers

No public page shows one of its shipment numbers, so there is no rule.

## Why there is no adapter

Its track and trace page, which maxpakket.nl links to, runs on the Mendrix transport system as a
script app. No public number has shown a known parcel's reply yet.

## Links

The track and trace page takes numbers typed into its form; there are no tracking links.
