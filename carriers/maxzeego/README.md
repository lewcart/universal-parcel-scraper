# MaxzeeGo

MaxzeeGo parcels use enabled universal providers. There is no dedicated adapter.

MaxzeeGo, run by Maxzee Go Pty Ltd from a depot in Auburn, Sydney, delivers online orders to homes
in Australia and New Zealand, large items especially, among them Temu sellers' orders, and offers
warehousing. Its site is maxzeego.com.

## Numbers

Its tracker asks for a package ID. No public page shows one or states its layout, so there is no
rule.

## Why there is no adapter

The Track Order box on its home page asks an open JSON service without a session, which answers an
unknown ID with not found. Its replies include the recipient's name and address. No public ID has
shown a known parcel's reply yet.

## Links

The Track Order box looks IDs up in place, so there are no tracking links.
