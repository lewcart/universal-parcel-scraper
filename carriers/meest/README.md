# Meest

Meest parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Meest's tracker returns a sender's S10-style number, and its API documentation shows a
hyphenated sender number. Meest publishes no shape of its own, so no rule claims them.

## Links

Meest's tracker lives on `t.meest-group.com` and signs each lookup in its script, so no link
opens one parcel.

## Testing

Provider live-test inputs and commands are in the [provider READMEs](../../providers/README.md).
