# Megacity Courier

Megacity Courier parcels use enabled universal providers. There is no dedicated adapter.

Megacity Courier Service, based in Kolkata since 2000, is a domestic courier with branches across
India. Its site is megacitycourier.in.

## Numbers

Its tracker takes an AWB number or a reference number. No public page shows one or states their
layout, so there is no rule.

## Why there is no adapter

The tracker posts the number with the page's form state, without a login or CAPTCHA, and answers an
unknown number with a not-found message. No public number has shown a known parcel's reply yet.

## Links

The tracker posts numbers from its form, so there are no tracking links.
