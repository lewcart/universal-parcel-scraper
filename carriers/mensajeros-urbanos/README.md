# Mensajeros Urbanos

Mensajeros Urbanos parcels use enabled universal providers. There is no dedicated adapter.

Mensajeros Urbanos, run by MU TEAM S.A.S. in Bogotá, delivers on demand and the same day with
independent drivers in cities of Colombia and Mexico, and runs dedicated and bulk deliveries for
businesses. Its site is mensajerosurbanos.com.

## Numbers

Its tracker takes a service id or a guide number. No public page shows one with the tracker's
answer, so there is no rule.

## Why there is no adapter

The home page's form asks the site whether a guide number has a tracking address of its own, and
otherwise opens the service's page on the delivery platform. That page asks the platform's API with
an access token the page holds. No public number has shown a known delivery's reply yet.

## Links

Tracking links carry the service id in the path after `/ext/seguimiento-domicilios/` on the delivery
platform.
