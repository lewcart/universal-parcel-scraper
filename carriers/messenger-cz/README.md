# Messenger

Messenger parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Messenger's tracker asks for an eight- or fifteen-character tracking number. Archived lookups
on it show eight hexadecimal characters, a layout that overlaps the eight-digit numbers of many
carriers, so no rule claims it.

## Links

`tracking.messenger.cz/{number}` opens one parcel; the tracker also reads
`tracking.messenger.cz/consignment/{number}`.
