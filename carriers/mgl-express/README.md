# MGL Express

MGL Express parcels use enabled universal providers. There is no dedicated adapter.

MGL Express, run by Magnate Group Logistics in Yangon since 2004, carries documents and parcels
within Myanmar and abroad. Its site is mglexpress.com.mm.

## Numbers

Its user guide shows screenshots of its app with waybills in two layouts: four letters and five
digits, and thirteen digits starting with 02. The tracker no longer finds them. One source does not
show how its numbers are built, and other carriers' rules read thirteen digits, so there is no rule.

## Why there is no adapter

The tracker shows a waybill's scans on a plain page without a login, takes several numbers separated
by commas and answers an unknown one with a not-found message in Burmese. No public number it still
knows has been found.

## Links

Tracking links carry the number as `waybill` on the waybills page.
