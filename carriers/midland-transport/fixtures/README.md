# Fixtures

Pages of `https://ship.midlandtransport.com/Tracking/TrackClientTrackings`, cut down to the
search form, the shipment and the markup the tracker serves around them, scripts and styles
left out. `delivered.html` is a Midland Courier parcel picked up in Ontario and delivered in Nova
Scotia after a delay, with the shipper's details and reference and one scan the page repeats.
`in-transit.html` is a parcel at its first sort facility, without an updated estimate.
`created.html` is a shipment Midland has not scanned yet, with the placeholder row the table
shows then. `not-found.html` is the line the tracker gives a number it does not hold.

Numbers, names, towns, the shipper's phone, email and reference, the dates and the status type
values are invented.
