# Mikropakket

Mikropakket parcels use enabled universal providers. There is no dedicated adapter.

Mikropakket, in Nieuwegein, carries valuable and sensitive parcels between businesses in the
Netherlands and Belgium, as an independent part of PostNL. Its site is mikropakket.nl.

## Numbers

No public page shows one of its parcel numbers or states their layout, so there is no rule.

## Why there is no adapter

The tracker asks for the recipient's postcode with the parcel number.

## Links

The tracker needs the postcode with the number, so there are no tracking links.
