# DHL eCommerce Türkiye

DHL eCommerce Türkiye parcels, formerly MNG Kargo, use enabled universal providers. There is no dedicated adapter.

## Numbers

MNG Kargo numbers in Şikayetvar complaints are twelve digits. Twelve digits are shared with
several carriers, so no rule claims them.

## Links

The old `mngkargo.com.tr/gonderitakip` page redirects to DHL eCommerce Türkiye's tracker,
whose form posts behind a captcha, so no link opens one parcel.

Provider live-test inputs and commands are in the [provider READMEs](../../providers/README.md).
