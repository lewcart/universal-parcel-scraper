# Möbel

Möbel parcels use enabled universal providers. There is no dedicated adapter.

Möbel (Möbel and Home Logistic Services, S.L.), based near Zaragoza, delivers bulky goods to homes
for online shops and retailers across mainland Spain and the Balearic Islands, with assembly and
old-appliance take-back, and runs contract logistics. Its site is mobelservices.com.

## Numbers

Its tracker takes the order reference. No public page shows one, so there is no rule.

## Why there is no adapter

Every lookup needs the phone number the order was placed with.

## Links

Lookups need the phone number, so there are no tracking links.
