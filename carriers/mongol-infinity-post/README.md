# Mongol Infinity Post

Mongol Infinity Post parcels use enabled universal providers. There is no dedicated adapter.

Mongol Infinity Post (Монгол Инфинити Шуудан, brand MyPost) is a private postal and express
operator in Mongolia, with first- and last-mile delivery, branches and a fulfilment centre
for online shops.

## Numbers

The parcel search on its home page asks for the parcel's registration number. Its first
example is a seven-digit number; the other two are an international postal item and a
zero-filled placeholder. Seven bare digits are a shape many carriers share, so no rule claims
them. International items keep the postal operator's own number, which generic postal
detection handles.

## Links

The home-page search shows the result in the page without changing its address. The site's
`/item/{number}` page lists a parcel's declared contents rather than its history, so no
address opens one parcel's tracking.
