# Moovin

Moovin parcels use enabled universal providers. There is no dedicated adapter.

Moovin (Moovin Mensajería Express S.A.), in Alajuela, delivers parcels and online orders in Costa
Rica and Honduras, with fulfilment, national routes and an API for shops. Its site is moovin.me.

## Numbers

Its tracker takes a guide number, and its API's examples show package ids as digits of no stated
length. No public number is known, so there is no rule.

## Why there is no adapter

Every lookup needs the recipient's surname.

## Links

Lookups need the recipient's surname, so there are no tracking links.
