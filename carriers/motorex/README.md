# Motorex

Motorex parcels use enabled universal providers. There is no dedicated adapter.

Motor Express Delivery Sdn. Bhd., founded in Skudai, Johor, in 2016, runs same-day and next-day
courier, dispatch and lorry deliveries for businesses in Johor Bahru, Kuala Lumpur and Selangor. Its
site is motorex.com.my.

## Numbers

Its pages give no layout and no public number is known, so there is no rule.

## Why there is no adapter

The tracker is an open page for each number, without a login or CAPTCHA, and answers an unknown
number with an error page. No public number has shown a known reply yet. An adapter can follow.

## Links

Tracking links carry the number in the path of `getTrackingList` pages at motorex.com.my.
