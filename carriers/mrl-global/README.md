# MRL Global

MRL Global parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

MRL Global, which also trades as MRL Logistics and Sampson Express, tracks freight by
consignment note number. Its tracking page and its track-and-trace API documentation show
ten-character numbers: four letters starting with C, then six digits. No rule claims them: the
layout falls inside C-chez-vous' ten-character rule, and two samples cannot show whether the
three letters after the C are a fixed range.

## Links

The tracking page opens one consignment from its `connoteno` query parameter.
