Synthetic replies of Meiteshun's Hualei tracker: `track.json` is the interface's record for a
whole script written in one go, from the collection to the delivery, whose destination rows end
with the recipient's town and postcode; `page.html` is the tracking page for an order found by
the shipper's reference, whose rows carry no place; `no-track.json` is the interface's answer
for a number it holds no row for, and `page-unknown.html` the page's answer for an unknown
number. Numbers, references, parties, places and clocks are invented.
