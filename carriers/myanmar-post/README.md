# Myanmar Post

Myanmar Post parcels use enabled universal providers. There is no dedicated adapter.

Myanmar Post is Myanmar's national post, once part of Myanma Posts and Telecommunications (MPT).
Its site is myanmarpost.com.mm.

## Numbers

Myanmar Post gives international items UPU S10 numbers ending `MM`. Generic postal detection
handles these numbers, so no rule for Myanmar Post claims them. Its tracker also takes the post's
own domestic label numbers, which no public page shows and which stay unclaimed.

## Why there is no adapter

Its tracker is a plain page whose address names the number, answering without a session or
CAPTCHA. No public number has shown a known item's reply yet. An adapter can follow.

## Links

`myanmarpost.com.mm/track/{number}` opens one item.
