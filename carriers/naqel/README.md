# Naqel Express

Naqel Express parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Naqel waybills are digit runs. Archived lookups on its tracker show eight digits in earlier
years and nine digits more recently, and one lookup has fourteen digits. Saudi Post, which owns
Naqel, accepts Naqel numbers of eight, nine, thirteen and fourteen digits in its own tracker.
No rule claims them, because many carriers print digit runs of these lengths.

## Links

The tracking form posts to `naqelexpress.com/en/sa/tracking/`. Archived lookups show that
`naqelexpress.com/en/Track/TrackShipment/{number}` opens one shipment; the same path also
appears without the language and under `/ar/`.
