# Nationex

Nationex parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

An aggregator offers a nine-digit Nationex sample. Nine digits are shared with several
carriers, so no rule claims them.

## Links

Nationex's tracker opens a number at `nationex.com/reperage/{number}`, or `/tracking/` in
English.

## Testing

Provider live-test inputs and commands are in the [provider READMEs](../../providers/README.md).
