# Netpost

Netpost parcels use enabled universal providers. There is no dedicated adapter.

Netpost, Công ty CP Chuyển phát nhanh Netpost Việt Nam, delivers express documents and
parcels across Vietnam and sends international shipments.

## Numbers

The waybill example on the carrier's former tracking form has fifteen digits. No rule claims
it: fifteen-digit runs are shared by many carriers, and the current form gives no layout.

## Links

`netpost.vn/Home/tra_cuu_van_don` opens one waybill from its `hawbNo` parameter; the home page
form builds this address.
