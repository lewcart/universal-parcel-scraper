# Nippon Express

Nippon Express parcels use enabled universal providers. There is no dedicated adapter.

Nippon Express (日本通運, NX) is a Japanese logistics group; this entry covers its domestic
parcel and air courier tracking.

## Numbers

The tracking number (お問い合わせ伝票番号) has eleven, twelve or fourteen digits and is often
printed with hyphens. The last digit is the rest modulo 7, the same check as Yamato, Sagawa
and Japan Post, so no rule claims these numbers.

## Links

`lp-trace.nittsu.co.jp/web/webarpaa702.srv` takes the number in `denpyoNo1` and lists its
status. The domestic small-parcel form on the group site posts the number instead.
