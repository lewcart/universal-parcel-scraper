# NK Logistic

NK Logistic parcels use enabled universal providers. There is no dedicated adapter.

NK Logistic, run by Nowe Kolory Gołdys, Zabojszcz sp.k. in Warsaw, ships Polish online sellers'
orders to Romania, Hungary, Bulgaria, Greece and Cyprus, with a fulfilment warehouse in Oradea and
local customer support. Its site is nklogistic.pl.

## Numbers

No public page shows one of its parcel numbers or states their layout, so there is no rule.

## Why there is no adapter

The tracker asks an open JSON service without a session or CAPTCHA, which answers an unknown number
with a not-found error. No public number has shown a known parcel's reply yet. An adapter can
follow.

## Links

Tracking links carry the number as `awb` on the tracker.
