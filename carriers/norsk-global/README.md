# Norsk Global

Norsk Global parcels use enabled universal providers. There is no dedicated adapter.

Norsk Global is a British international express and e-commerce shipping company that hands
parcels to partner carriers abroad.

## Numbers

An archived lookup on Norsk's tracker shows a reference of `NOR`, four digits, a country code
and eleven digits. A customer's review that Norsk answered gives `PKG` and twelve digits. One
sample of each is too few to fix a layout, so no rule claims them.

## Links

Norsk's tracker opens one parcel at `norsk.trackmyparcel.info/gb/tracking/{number}`. Its
search form builds that address; older lookups leave out the language segment.
