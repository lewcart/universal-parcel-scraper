# Fixtures

`delivered.json` follows the reply of the Freightways `tracking-events` lookup, oldest scan
first as it lists them.

It is a customer printed label under a sender's account of letters and digits, scanned by Now
Couriers, with a rural notice and a delivery photo and authority-to-leave tag.

An unknown number gets an empty HTTP 204 reply, so it has no fixture.

Numbers, names, places, branches, tags, links and clocks are invented.
