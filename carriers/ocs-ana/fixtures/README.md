# Fixtures

Each file follows OCS's English history page for one waybill: a summary row and a detail table
that echo the waybill with its shipper's and receiver's places, pieces and weights, then the
scans newest first, each an activity, a wall clock, a station and a memo, held in read-only
fields. `delivered.html` is an import into Japan through China and Hong Kong, with the
contracted delivery company's own scans and its slip number run into the delivery memo.
`export.html` is an export from Japan still on its way, up to its flight, with its customs
declarations. `not-found.html` is the answer for a waybill OCS does not hold. The site's
third-party scripts are left out.

Numbers, places, weights and clocks are invented.
