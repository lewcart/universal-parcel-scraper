# Pavan Courier Service

Pavan Courier Service parcels use enabled universal providers. There is no dedicated adapter.

Pavan Courier Service is a domestic courier network based in Gujarat, India.

## Numbers

The tracker takes AWB numbers. A lookup archived from the former tracker shows an eight-digit
AWB number. Eight-digit runs are printed by many other carriers, so no rule claims them.

## Links

The tracking page sends the number as `TrackingNo` to `Home/Tracking`, so that address opens
one parcel. Lookups archived from the former site carry it as `txtawbno` on `Tracking.aspx`.
The number is read from both.
