# PCS Logistics

PCS Logistics parcels use enabled universal providers. There is no dedicated adapter.

PCS Logistics, formerly PCS Courier, is a Vietnamese courier based in Hanoi with domestic
express and international services. Its tracker is on pcs-logistics.com.

## Numbers

The tracker's own examples, on the PCS Courier site and its successor, are fifteen-digit
waybills. Fifteen digits are printed by many carriers, so no rule claims them. The same page
once listed a twelve-digit example whose issuer it does not name; it stays unclaimed and in
quarantine.

## Links

The tracking box opens `pcs-logistics.com/{language}/track-trace?code={number}`, with one
`code` for each number; the first one is read.
