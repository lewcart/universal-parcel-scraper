# PDQ Cargo Trader

PDQ Cargo Trader parcels use enabled universal providers. There is no dedicated adapter.

PDQ Cargo Trader is a Chilean transport and distribution company with its own branch network,
carrying business and e-commerce shipments across Chile.

## Numbers

PDQ guide numbers are twelve digits, a run many carriers share, so no rule claims them. The
tracker also searches shipper references and asks for the commune, the dispatch date, the
recipient or the guide number when a reference matches several shipments.

## Links

`www.pdq.cl/tracking?q={number}` opens one shipment; the home page search builds that address.
