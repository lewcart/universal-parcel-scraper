# Penta Express

Penta Express parcels use enabled universal providers. There is no dedicated adapter.

Penta Express, based in Karachi since 1997, carries documents and parcels within Pakistan and
abroad, with a customer portal and a Shopify app for online shops. Its site is pentaexpress.com.

## Numbers

No public page shows one of its numbers or states their layout, so there is no rule.

## Why there is no adapter

The tracking page reads the number from its address and draws its answer on the server from an open
JSON service, which answers an unknown number with an empty list. No public number has shown a known
parcel's reply yet. An adapter can follow.

## Links

Tracking links carry the number as `tracking_id` on the tracking page.
