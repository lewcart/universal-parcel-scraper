# Perú Box Air

Perú Box Air parcels use enabled universal providers. There is no dedicated adapter.

Perú Box Air SAC, in Callao, is an international courier and customs agent with its own customs
code. It brings online purchases from the United States to buyers' doors in Peru and handles cargo
and customs clearance. Its site is peruboxair.pe.

## Numbers

Its tracker takes an air or sea guide number and gives no layout or example. No public number is
known, so there is no rule.

## Why there is no adapter

The tracking page asks an open JSON service of its tracking software's vendor without a login or
CAPTCHA, which answers an unknown number with a not-found status. It allows sixty requests every
fifteen minutes. No public number has shown a known parcel's reply yet.

## Links

The tracking page reads no number from its address, so there are no tracking links.
