# Pitt Ohio

Pitt Ohio freight shipments use enabled universal providers. There is no dedicated adapter.

## Numbers

Pitt Ohio tracks shipments by PRO number. Aggregator samples are ten digits, all starting
`504`. Ten digits are shared by many carriers and the prefix rests on aggregator samples only,
so no rule claims them. The tracker also searches by pickup number, which is not a tracking
number.

## Links

Addresses archived from Pitt Ohio's site put a PRO number in `?pro=` on
`pittohio.com/myPittOhio/Shipping/LTL/TraceRequest`.
