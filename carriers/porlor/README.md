# PorLor Express

PorLor Express parcels use enabled universal providers. There is no dedicated adapter.

PorLor Express Co., Ltd. (บริษัท ปอลอ เอ็กซ์เพรส จำกัด), registered in Bangkok in 2006, delivers
parcels for online sellers and private senders across Thailand through its own hubs and drivers, with
cash on delivery. Its site is porlor.co.th.

## Numbers

Its pages give no layout and no public number is known, so there is no rule. Some parcels are handed
to Thailand Post's EMS for the last leg.

## Why there is no adapter

The tracker asks an open JSON service with the number alone, with a fixed credential from its public
page and no login or CAPTCHA, and answers an unknown number with an empty list. No public number has
shown a known reply yet. An adapter can follow.

## Links

Tracking links carry the number as `search` on the `Tracking` page at porlor.co.th.
