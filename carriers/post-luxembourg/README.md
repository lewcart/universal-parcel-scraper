# POST Luxembourg

POST Luxembourg items use enabled universal providers. There is no dedicated adapter.

## Numbers

A Trustpilot review gives a Luxembourg S10 number. International items use the UPU S10 layout
and stay with the generic postal carrier.

## Links

POST Luxembourg's Track & Trace app reads no number from its address, so no link opens one
parcel.

## Testing

Provider live-test inputs and commands are in the [provider READMEs](../../providers/README.md).
