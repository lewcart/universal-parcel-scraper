# Posta Kenya

Posta Kenya parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

The Postal Corporation of Kenya tracks letters, parcels and EMS items by UPU S10 numbers ending
in `KE`. Generic postal detection handles these numbers, so no rule for Posta Kenya claims
them.

## Links

The tracker at `postglobal.posta.co.ke/postglobaltrack/Track.aspx` posts the number from its
form and has no address for one item.
