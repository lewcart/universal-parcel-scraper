# Fixtures

`form.html` is the tracking page's form as it opens. `answer.html` is the form's answer for a code
the tracker holds: the form again, the code in its field, and the script that opens the result
page in a popup. `not-found.html` is its answer for a code it has no information for, with the
alert in place of the popup.

`delivered.html` is the result page of an item posted in Kenya and delivered abroad: the counter
and dispatch scans, the office of exchange in Kenya, customs abroad with one scan repeated, a
failed attempt with its reason and measure at an office written as a postcode, and the delivery
with who signed and their identity document. Its details name the sender, the addressee and who
took delivery, and the code is in lower case, as the tracker stores some. `inbound.html` is mail
from abroad, from the sending post's office number to Kenyan offices whose places have a second
line. `no-session.html` is the result page opened without a session holding a lookup.

Numbers, names, places, clocks and form state are invented.
