# Pošta na Severna Makedonija

Pošta na Severna Makedonija items use enabled universal providers. There is no dedicated
adapter.

## Numbers

The tracker looks up UPU S10 numbers, two letters, nine digits and two letters, including items
sent from abroad. These stay with the generic postal carrier; no rule of its own is needed.

## Links

The tracking page reads the number from `tn` and loads the history from the post's tracking
service.
