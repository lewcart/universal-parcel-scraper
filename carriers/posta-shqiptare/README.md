# Posta Shqiptare

Posta Shqiptare items use enabled universal providers. There is no dedicated adapter.

## Numbers

Posta Shqiptare's tracker accepts only the UPU S10 layout, two letters, nine digits and two
letters, and checks it before searching. Its items end in `AL` and stay with the generic postal
carrier; no rule of its own is needed.

## Links

The tracking form on the main site posts the code to the site's search service. The e-Posta
site reads the code from the last part of its tracking address.
