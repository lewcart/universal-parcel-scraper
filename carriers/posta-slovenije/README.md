# Pošta Slovenije

Pošta Slovenije items use enabled universal providers. There is no dedicated adapter.

## Numbers

Pošta Slovenije's tracking-service page uses an S10 number as its example. International items
use the UPU S10 layout and stay with the generic postal carrier.

## Links

The tracker moved from `sledenje.posta.si` to the Moja Pošta app, whose script reads a number
from `?trackingNumber=` on `moja.posta.si/tracking`.

Provider live-test inputs and commands are in the [provider READMEs](../../providers/README.md).
