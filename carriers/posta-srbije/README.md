# Pošta Srbije

Pošta Srbije items use enabled universal providers. There is no dedicated adapter.

## Numbers

An aggregator page prints a Serbian EMS number. International items use the UPU S10 layout and
stay with the generic postal carrier.

## Links

Pošta Srbije's tracker posts the number back to its page behind a reCAPTCHA, so no link opens
one parcel.

Provider live-test inputs and commands are in the [provider READMEs](../../providers/README.md).
