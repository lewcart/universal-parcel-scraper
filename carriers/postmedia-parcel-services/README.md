# Postmedia Parcel Services

Postmedia Parcel Services parcels use enabled universal providers. There is no dedicated
adapter.

Postmedia Parcel Services is the parcel delivery network of Postmedia, the Canadian news
publisher, and continues the parcel business of Brunswick News Inc. Amazon.ca names it BNI. It
delivers across Canada, including Amazon parcels.

## Numbers

Archived lookups on its tracker show BNI followed by nine digits, but each of them also carries
the recipient's postal code, so none is kept. The corpus is empty and no rule claims the
layout.

## Links

The tracker asks for the parcel number and the recipient's postal code.
`postmediaparcelservices.com` with `bniTrackingID` and `bniPostalCode` opens one parcel;
without the postal code no address does, so there is no link template.
