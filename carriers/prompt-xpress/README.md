# Prompt Xpress

Prompt Xpress parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Prompt Xpress's former tracking page gave its formats as `MC` or `RP` and eight digits, or `SP`
and nine digits. Archived addresses on its site show the two-letter layout, one with `NC`.
`prompt-xpress-1` suggests the carrier for these layouts at low confidence, since other
carriers print similar numbers.

## Links

The tracker on promptxpress.lk posts the number in a form, so no address opens one item. The
former site's `/Home/Tracking/{number}` addresses returned errors when archived.
