# Pronto Lanka

Pronto Lanka parcels use enabled universal providers. There is no dedicated adapter.

Pronto Lanka is a domestic courier network in Sri Lanka.

## Numbers

The tracking field on the home page takes any tracking ID of at least three characters, and
the carrier publishes no layout. A lookup archived from its early tracker shows an eight-digit
ID with leading zeros. Digit runs of that length are printed by many other carriers, so no
rule claims them.

## Links

The home page posts the tracking ID to the carrier's tracking service and shows the result on
the same page, so no address opens one parcel. Lookups archived from the early tracker carry
the ID as `ID` on `trackinfo.asp` and `T2.asp`; the number is read from them.
