# PTT

PTT parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

PTT Kargo numbers in Şikayetvar complaints are thirteen digits or `KP` and eleven digits;
complainants also type the prefix in lower case. `ptt-1` claims the `KP` shape. Thirteen digits
are shared with several carriers, so no rule claims them. International items use the UPU S10
layout and stay with the generic postal carrier.

## Links

PTT's tracker is a window on its home page that asks for a verification token, so no link
opens one parcel.
