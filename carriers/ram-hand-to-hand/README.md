# RAM Hand-to-Hand Couriers

RAM Hand-to-Hand Couriers parcels use enabled universal providers. There is no dedicated
adapter.

RAM is a South African courier for high-value and secure deliveries. International shipments
travel on DHL Express waybills, which belong to DHL.

## Numbers

Archived lookups on RAM's tracker show waybills of `RAM` followed by eight digits, and shorter
references of one or a few letters followed by six or seven digits. Rule `ram-hand-to-hand-1`
suggests RAM for the `RAM` waybills at low confidence, since none of them has been seen with a
history. A letter followed by seven digits is also a GLS layout, and the other references are
too generic to point to RAM, so no rule claims them.

## Links

RAM's tracker reads the number from the path, as in `ram.co.za/track/<number>`; older addresses
use `/Track/`.
