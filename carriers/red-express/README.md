# Red Express

Red Express parcels use enabled universal providers. There is no dedicated adapter.

Red Express (ОсОО «РЭД Экспресс») carries road freight from Bishkek and Osh in Kyrgyzstan to Russian
cities and to marketplace warehouses there. Its site is redexpress.kg.

## Numbers

Its tracker asks for the waybill number (номер накладной) without stating a layout, and no public
number is known, so there is no rule.

## Why there is no adapter

Its tracker asks an open JSON service with the number alone, without a login or CAPTCHA. No public
number has shown a known reply yet. An adapter can follow.

## Links

The tracker opens in a window on the home page, without a per-shipment address, so there are no
tracking links.
