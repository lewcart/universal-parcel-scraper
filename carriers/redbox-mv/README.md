# Redbox

Redbox parcels use enabled universal providers. There is no dedicated adapter.

Redbox, run by RB International in Malé, delivers parcels in the Maldives and ships them from
abroad. Its site is redbox.mv.

## Numbers

No public page shows one of its tracking numbers or states their layout, so there is no rule.

## Why there is no adapter

The tracking page asks an open JSON service without a session, which answers an unknown number
with not found. No public number has shown a known parcel's reply yet. An adapter can follow.

## Links

Tracking links carry the number as `tracking_number` on the tracking page.
