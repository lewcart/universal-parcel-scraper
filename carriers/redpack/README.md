# Redpack

Redpack parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Redpack's own tracking field shows nine-digit guide numbers as examples. Nine digits are shared
with several carriers, so no rule claims them.

## Links

Redpack's tracker adds a fresh reCAPTCHA token to every search, so no link opens one parcel.

## Testing

Provider live-test inputs and commands are in the [provider READMEs](../../providers/README.md).
