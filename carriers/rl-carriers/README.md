# R+L Carriers

R+L Carriers freight shipments use enabled universal providers. There is no dedicated adapter.

## Numbers

R+L Carriers PRO numbers in aggregator samples are nine digits. Nine digits are shared with
several carriers, so no rule claims them.

## Links

R+L's tracing form sends a PRO number to
`rlcarriers.com/freight/shipping/shipment-tracing?pro={number}&docType=PRO&source=web`.

Provider live-test inputs and commands are in the [provider READMEs](../../providers/README.md).
