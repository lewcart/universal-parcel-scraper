# Rodonaves

Rodonaves parcels use enabled universal providers. There is no dedicated adapter.

Rodonaves Transportes e Encomendas LTDA, formerly RTE Rodonaves, is a road carrier based in Ribeirão
Preto that carries part loads and parcels across Brazil, with express and air services. Its site is
rodonaves.com.br.

## Numbers

Its tracker takes a protocol number of up to twelve digits, or an invoice or CT-e number with the
sender's or recipient's CPF or CNPJ. No public number is known, and other carriers' rules read
numbers of that shape, so there is no rule.

## Why there is no adapter

The tracker is behind a CAPTCHA. Its tracking API is for customers with an access token.

## Links

The tracking page can start a lookup from its address, but each lookup still needs the CAPTCHA, so
there are no tracking links.
