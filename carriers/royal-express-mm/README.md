# Royal Express Myanmar

Royal Express Myanmar parcels use enabled universal providers. There is no dedicated adapter.

Royal Express is a Yangon-based domestic parcel and express network in Myanmar.

## Numbers

The tracker asks for the waybill number. Its own form placeholders give two layouts: a
Yangon code, eleven digits and a destination code on the tracking page, and on the home page a
Yangon code, seven digits and a three-letter code joined by a slash to three letters and six
digits. No public waybill shows how far either layout reaches, so no rule claims them.

## Links

The tracking form posts the waybill with a session token to `royalx.net/tracking`, so no
address opens one parcel.
