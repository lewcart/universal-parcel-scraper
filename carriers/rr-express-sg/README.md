# RR Express

RR Express parcels use enabled universal providers. There is no dedicated adapter.

RR Express is a Singapore islandwide courier, formerly TCK Express. The company kept its
registration and its tracker when it took the new name. Its tracker is a GETOnline page
hosted for it.

## Numbers

Lookups archived from the TCK Express tracker show ten-digit numbers. Ten digits are printed by
many carriers, so no rule claims them.

## Links

The site's tracking box opens `tracking.frontierforce.com/tracking.aspx?cn={number}&stid=rr`.
GETOnline serves other couriers on the same host under other `stid` values, so no link rule
reads numbers from it. Older lookups put the number in `cn` on
`tckexpress.com/trackresult.aspx`; that site is gone.
