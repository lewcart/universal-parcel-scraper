# RRS Logistics

RRS Logistics parcels use enabled universal providers. There is no dedicated adapter.

RRS (日日顺供应链), part of the Haier group and based in Qingdao, delivers and installs large items such as
appliances and furniture across China. Its site is rrswl.com.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

Its order search takes up to ten numbers and a four-digit image CAPTCHA. No public number is known to see a
found reply.

## Links

Its order search looks numbers up in place, so no address names one.
