# Ryder Last Mile

Ryder Last Mile parcels use enabled universal providers. There is no dedicated adapter.

Ryder Last Mile, part of Ryder System, Inc., delivers big and bulky goods such as furniture,
mattresses and appliances to homes across the United States for retailers, with white-glove service
and two-hour delivery windows scheduled by phone. Its site is ryder.com.

## Numbers

Its tracker takes the retailer's order number or the customer's phone number. Ryder Last Mile prints
no tracking number of its own, so there is no rule.

## Why there is no adapter

Every lookup needs the delivery ZIP code with the order or phone number.

## Links

The tracker's addresses carry the delivery ZIP code, so no link rule reads them.
