# Saia

Saia freight shipments use enabled universal providers. There is no dedicated adapter.

## Numbers

Saia PRO numbers in aggregator samples are eleven or twelve digits. Neither length is
distinctive, so no rule claims them.

## Links

Saia's tracker reads a PRO number from `?pro=` on `saia.com/track`.

## Testing

Provider live-test inputs and commands are in the [provider READMEs](../../providers/README.md).
