# Sailpost

Sailpost parcels use enabled universal providers. There is no dedicated adapter.

Sailpost is a private Italian postal network of franchised agencies that delivers letters,
registered mail, documents for public bodies and parcels. HR Parcel, the group's e-commerce
parcel service, has its own tracker and entry; Sailpost's tracker on `sailpost.it` answers
the codes of items Sailpost itself carries.

## Numbers

No public source quotes a Sailpost shipment code, so the corpus is empty and no rule claims a
layout.

## Links

Sailpost's tracking page sends the code in a form, and no address opens one item.
