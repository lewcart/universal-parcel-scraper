# Fixtures

Replies of the tracking lookup on urm.sat.ua, asked without SAT's key as the adapter asks, in
Ukrainian, with the current state and the states oldest first. `delivered.json` is cargo
listed for a pickup, accepted at a branch, sent through a terminal and issued at the delivery
branch; one terminal state is repeated. `in-transit.json` is cargo for the door, handed to the
courier at the delivery branch. `not-found.json` is the answer for a waybill SAT does not hold.

Numbers, references, branches, towns, addresses, coordinates and days are invented.
