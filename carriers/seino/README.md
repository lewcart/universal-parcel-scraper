# Seino Transportation

Seino Transportation parcels use enabled universal providers. There is no dedicated adapter.

Seino Transportation (西濃運輸) is a Japanese parcel and freight carrier.

## Numbers

The tracking number (お問い合わせ番号) has ten digits, sometimes printed with hyphens. No check
digit has been found, and bare ten-digit numbers are printed by many carriers, so no rule
claims them.

## Links

`track.seino.co.jp/cgi-bin/gnpquery.pgm` takes the number in `GNPNO1` and opens its status.
