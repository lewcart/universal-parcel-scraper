# SFYD Express

SFYD Express parcels use enabled universal providers. There is no dedicated adapter.

SFYD Express (云速递) runs air freight lines for online sellers from Shenzhen and Yiwu to Europe,
North America, Southeast Asia and the Middle East. Its site is sfydexpress.com.

## Numbers

No public page shows one of its waybill numbers, so there is no rule.

## Why there is no adapter

The tracking page asks an open JSON service without a session, which gives an empty list for an
unknown number. No public number has shown a known parcel's reply yet. An adapter can follow.

## Links

Tracking links carry the number as `c` on the tracking page.
