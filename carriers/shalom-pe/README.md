# Shalom

Shalom parcels use enabled universal providers. There is no dedicated adapter.

Shalom Empresarial S.A.C. is a Peruvian parcel and cargo courier. It carries shipments across the
country through its own network of agencies, where senders drop them off and recipients collect them
or have them delivered. Its site is shalom.com.pe.

## Numbers

Its tracker takes an order number of eight to ten digits together with the four-character order code
on the sender's receipt. Many carriers' rules read eight to ten digits, and the number alone cannot
be tracked, so there is no rule.

## Why there is no adapter

Every lookup needs the order code as well as the number, and the tracker is behind a CAPTCHA.

## Links

The tracker's addresses for one order carry its order code, so there are no tracking links.
