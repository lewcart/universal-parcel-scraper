# Shenghang International Logistics

Shenghang International Logistics parcels use enabled universal providers. There is no dedicated adapter.

Shenghang International Logistics (盛航国际物流), run by Guangzhou Shenghang Freight Agent, gathers online
orders in China and ships them on to Malaysia and Singapore. Its site is shenghanggj.com.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

Its consolidation query reads the number from the address and shows the scans without a login. No public
number is known to see a found reply.

## Links

Tracking links carry the number as `order_tracking_search` on its `checkexpress` page when `act` is `cx`.
