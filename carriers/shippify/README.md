# Shippify

Shippify parcels use enabled universal providers. There is no dedicated adapter.

Shippify, Inc., founded in 2015, runs same-day and last-mile deliveries with independent drivers
for shops in Brazil, Chile, Ecuador, Mexico and Peru. Its site is shippify.co.

## Numbers

Its delivery ids read t-, five or six letters, a hyphen and up to five digits. None has been
seen answering without its share token, so there is no rule.

## Why there is no adapter

A delivery's tracking page shows it only with the share token its link carries; without it, the
page answers that it was not found.

## Links

Tracking links carry a share token that opens the delivery, so they are not read.
