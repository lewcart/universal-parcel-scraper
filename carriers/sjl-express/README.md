# SJL Express

SJL Express parcels use enabled universal providers. There is no dedicated adapter.

SJL Express (上海捷利货运有限公司), based in Shanghai, runs air lines for cross-border online
orders from China, notably to Taiwan and Korea. Its site is sjlexpress.com.

## Numbers

The tracker's placeholder gives SJL and nine digits as a layout, not a real number. No public
page shows one, so there is no rule.

## Why there is no adapter

Every lookup needs an image CAPTCHA.

## Links

The tracker takes numbers typed into its form with the CAPTCHA, so there are no tracking links.
