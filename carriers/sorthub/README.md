# SortHub

SortHub parcels use enabled universal providers. There is no dedicated adapter.

SortHub (SORT HUB PTY. LTD.), in Melbourne's west, is the parcel sorting and dispatch hub of Mercury
Retail Group, the company behind the online retailer The Nile. It tracks the parcels the group's
retail clients send through it. Its tracker is at track.sorthub.com.

## Numbers

Its tracker gives no layout or example, and no public number is known, so there is no rule.

## Why there is no adapter

The tracker is a plain page without a login or CAPTCHA that answers an unknown number as not found.
No public number has shown a known parcel's reply yet. An adapter can follow.

## Links

Tracking links carry the number in the path after `/track/`.
