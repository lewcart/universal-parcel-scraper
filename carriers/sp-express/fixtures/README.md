# Fixtures

Each page follows the tracker's page for one number: the search forms, the progress rail, the
status bar, the partner box, the history, the order details and the Reference link.

`delivered.html` has the layout with a place column and clocks to the minute: a delivery
relayed from the partner, whose place column names who signed, with one scan repeated.
`in-transit.html` has the layout that puts the place in brackets, with clocks to the second:
Polish partner scans, a hub scan dated at midnight, a wording no map knows and a dash for a
place. `archived.html` is an older parcel whose history is archived. `cainiao.html` is a parcel
on the Cainiao page, with a consignment reference in brackets and a weight in grams.
`not-found.html` is the search page an unknown number is sent back to, with its notice.

Numbers, names, places, postcodes, clocks and the site key are invented.
