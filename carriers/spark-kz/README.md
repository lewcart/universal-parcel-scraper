# Spark

Spark parcels use enabled universal providers. There is no dedicated adapter.

Spark Logistics (ТОО "Spark Логистика"), based in Almaty and on the market since 2010, carries part
and full truck loads across Kazakhstan, runs fulfilment warehouses and a terminal at Khorgos, and
delivers parcels for online shops. Its site is spark.kz.

## Numbers

Its tracker takes Spark's waybill number. Its pages give no layout and no public number is known, so
there is no rule.

## Why there is no adapter

The tracker on the home page asks an open JSON service with the number alone, without a login or
CAPTCHA, and answers an unknown number with a not-found reply. No public number has shown a known
reply yet. An adapter can follow.

## Links

The tracker has no per-shipment address, so there are no tracking links.
