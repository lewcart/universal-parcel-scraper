# Gokulam Speed & Safe

Gokulam Speed & Safe parcels use enabled universal providers. There is no dedicated adapter.

Gokulam Speed & Safe is a courier network in Kerala, India.

## Numbers

The tracker takes AWB numbers. A complaint gives an eight-digit number. Eight-digit runs are
printed by many other carriers, so no rule claims them.

## Links

The tracking page looks the number up by script and does not read it from its address, so no
address opens one parcel.
