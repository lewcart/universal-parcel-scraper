# SPFLY

SPFLY parcels use enabled universal providers. There is no dedicated adapter.

SPFLY-LOG Transportes e Logística Ltda, in Guarulhos beside São Paulo's international airport,
carries goods by road and runs a warehouse for storage, picking, kitting and online-shop fulfilment.
Its site is spfly.com.br.

## Numbers

Its tracker takes an invoice (nota fiscal) number with the sender's, recipient's or payer's CPF or
CNPJ, and readers get no number of its own. A page for one client's buyers takes that client's order
number alone. There is no rule.

## Why there is no adapter

Every lookup needs an invoice number and a CPF or CNPJ, or one client's order number.

## Links

The tracker posts its form, so there are no tracking links.
