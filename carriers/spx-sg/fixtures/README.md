# Fixtures

`delivered.json` follows the reply of `get_order_info` with `language_code=en`, newest scan
first, with every field a scan carries: a parcel from an overseas sorting centre through
Singapore import to the door, with hidden rows, a repeated export clearance and two delivery
rounds. `not-found.json` is the answer for a number the lookup does not find.

Numbers, IDs, places, coordinates and clocks are invented.
