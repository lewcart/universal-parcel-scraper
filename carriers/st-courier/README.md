# ST Courier

ST Courier parcels use enabled universal providers. There is no dedicated adapter.

ST Courier is a domestic courier network in India, based in Chennai.

## Numbers

The tracking field on the home page takes digits only and searches once eleven are typed.
Complaints quote eleven-digit AWB numbers, and lookups archived from the carrier's older
tracker show twelve-digit ones. Digit runs of these lengths are printed by many other
carriers, so no rule claims them.

## Links

The current tracker posts the number and opens a result page without it, so no address opens
one parcel. Lookups archived from the older tracker carry the number as `awb_no` or `awb` on
`stcourier.com/cgi_bin/show_status1.php`; the number is read from them.
