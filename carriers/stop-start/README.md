# Stop Start

Stop Start parcels use enabled universal providers. There is no dedicated adapter.

Stop Start Transport Ltd, in Worcester, delivers large, heavy and fragile goods such as bathroom,
heating and radiator products for online retailers across Great Britain, with two-person crews. Its
site is stop-start.co.uk, and its tracker is at track-my-order.co.uk.

## Numbers

Its tracker takes the retailer's customer order number. Its placeholder is four letters and three
digits, but the layout depends on the retailer, and no public number is known, so there is no rule.

## Why there is no adapter

The tracker is a plain page that finds an order from its number alone, without a login or CAPTCHA,
and says when it finds none. No public number has shown a known delivery's reply yet. An adapter can
follow.

## Links

Tracking links carry the order number as `s` on track-my-order.co.uk.
