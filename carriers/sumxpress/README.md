# Sumxpress

Sumxpress parcels use enabled universal providers. There is no dedicated adapter.

Sumxpress (速玛物流), based in Shenzhen, runs parcel lines for online sellers to Australia, some handed to
Australia Post's eParcel service. Its site is sumxpress.com.

## Numbers

Parcels handed to Australia Post carry its number too. No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

Its query page, on its order system at oms.sumxpress.com, looks numbers up without a login. No public number
is known to see a found reply.

## Links

Tracking links carry the number as `trackingNo` in the address fragment of its query page.
