# Suto Logistics

Suto Logistics parcels use enabled universal providers. There is no dedicated adapter.

Suto Logistics (速通物流), run by Jiangsu Sutong Logistics in Wuxi, carries less-than-truckload
and express freight across China through franchised outlets. Its site is sut56.com.

## Numbers

No public page shows one of its waybill numbers or states their layout, so there is no rule.

## Why there is no adapter

The query page reads the number from its address and draws its answer on the server without a
session. No public number has shown a known shipment's reply yet.

## Links

Tracking links carry the number as `no` on the query page.
