# swftbox

swftbox parcels use enabled universal providers. There is no dedicated adapter.

swftbox, run by swftbox Delivery Services in Dubai, delivers online shops' orders the same day or
the next across the United Arab Emirates. Its site is swftbox.com.

## Numbers

Its tracker takes ids of eight or ten letters and digits, with an optional suffix for each piece.
Other carriers' rules read such shapes and no public id is known, so there is no rule.

## Why there is no adapter

The tracker asks a GraphQL service that answers without a login. No public id has shown a known
parcel's reply yet.

## Links

Recipients get tracking links by WhatsApp that open their delivery, where they can change the
address or pay. These links work as access tokens, so no link rule reads them.
