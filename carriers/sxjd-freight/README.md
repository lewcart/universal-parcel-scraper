# SXJD Freight

SXJD Freight parcels use enabled universal providers. There is no dedicated adapter.

SXJD Freight (顺心捷达), part of the SF group, carries less-than-truckload freight and large parcels across
China through a franchise network. Its site is sxjdfreight.com.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

Its waybill query takes up to ten numbers separated by commas or spaces and looks them up without a login.
No public number is known to see a found reply.

## Links

Its waybill query looks numbers up in place, so no address names one.
