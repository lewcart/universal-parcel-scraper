# Fixtures

`delivered.html` and `in-transit.html` follow the TraceDetail page, trimmed of its menus: the
hidden status table the server writes, newest scan first, the page's display template and the
script that lays the table out. `delivered.html` is a twelve-digit waybill collected, sent
through a transfer centre, rescheduled after a first delivery round and delivered; one branch
is plain text instead of a link. `in-transit.html` is a ten-digit waybill at a transfer centre.

`not-found.html` is the page's notice for a number without a status, which echoes the number.

Numbers, branches, centres and clocks are invented.
