# Tamdis

Tamdis (Tamdis by JP, of the Jacky Perrenot group) delivers bulky goods such as furniture,
appliances and TVs to the home by appointment in Spain and Portugal, and can unpack, assemble
or set them up. Its parcels use enabled universal providers; there is no dedicated adapter.

## Numbers

Recipients get a per-shipment link by SMS or email rather than a number to type. The one
public Tamdis reference is a letter, seventeen digits, `T` and a digit, which ParcelsApp tracks
under Tamdis. One sample does not establish the family, so no rule claims it and the user
picks Tamdis.

## Links

The site has no page that looks up a number. The link in Tamdis's messages opens a page keyed
by an opaque token, which is a capability URL rather than a tracking number, so no link rule
reads it.
