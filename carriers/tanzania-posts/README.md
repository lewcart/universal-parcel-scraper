# Tanzania Posts Corporation

Tanzania Posts Corporation parcels use enabled universal providers. There is no dedicated
adapter.

## Numbers

Tanzania Posts Corporation's letters, parcels and EMS items carry UPU S10 numbers ending in
`TZ`. Generic postal detection handles these numbers, so no rule for Tanzania Posts
Corporation claims them.

## Links

The Posta Tracking System at `tracking.posta.co.tz` posts the number from its search form. An
archived lookup also passed it as `id` on `/index.php/Tracking/dashboard_tracking_information`.
