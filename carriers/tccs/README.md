# TCCS

TCCS parcels use enabled universal providers. There is no dedicated adapter.

TCCS is an international courier from Mumbai. It collects across India and hands shipments to
partners abroad, whose forwarding number its tracker shows.

## Numbers

TCCS air waybills are plain digit runs; the archived lookup on its own tracker shows seven
digits. No rule claims them, since many carriers print digit runs of that length.

## Links

The current tracking page posts the number from a form, so no address opens one parcel. The
older tracker opened one at `Tracking.aspx?txtawbno=` followed by the number.
