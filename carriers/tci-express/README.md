# TCI Express

TCI Express parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

TCI Express tracks a consignment by its docket number, nine or ten digits. Digit runs of these
lengths are shared with other carriers, so no rule claims them.

## Links

The tracker opens a docket from its `trackshipment` parameter, which can list several dockets
separated by commas; those addresses are recognized.
