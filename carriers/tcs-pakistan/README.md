# TCS

TCS parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

TCS consignment numbers seen in archived lookups on its tracker and in customer reviews are
eleven, twelve or fourteen digits. Digit runs of these lengths are printed by many carriers and
no known prefix or check digit sets TCS apart, so no rule claims them; a caller names the
carrier or pastes a tracking page link.

## Links

The search box on tcsexpress.com opens one consignment at `/track/` followed by the number. The
library reads the number from that address.
