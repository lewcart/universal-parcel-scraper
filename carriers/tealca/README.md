# Tealca

Tealca parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Tealca guías seen on its own trackers are seven or eight digits. Runs of digits this short are
printed by many carriers, so no rule claims them. The tracker also accepts a pre-guía, chosen
with a separate option.

## Links

`tealca.com/rastrear-envio/` reads the guía from `?tracking=` and renders its history. The
former tracker read it from the path `/tracking/guia/<number>`.
