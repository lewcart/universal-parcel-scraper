# Team Global Express

Team Global Express parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Team Global Express, formerly Toll's Global Express business, tracks shipment, consignment and
item numbers in MyTeamGE. Numbers seen in reviews and archived lookups are thirteen digits,
twelve digits, nine digits, or a four-character sender prefix and six digits; deliveries for JB
Hi-Fi also use other prefixes. All of these are shapes other carriers print: four letters and
six digits is C Chez Vous's layout, and the digit runs are shared widely. No rule claims them.

## Links

MyTeamGE reads a number from `externalSearchQuery` on `www.myteamge.com/`, and the delivery
page for JB Hi-Fi orders reads one from `shipmentID` on `teamglobalexp.com/myparcel`. Both
appear in archived lookups.
