# Tej Couriers

Tej Couriers parcels use enabled universal providers. There is no dedicated adapter.

Tej Couriers is a domestic courier from Kolhapur, part of the Ghatge group, that delivers
across Maharashtra, Karnataka and Goa.

## Numbers

Tej Couriers consignment numbers are eight digits, as customers quote them in complaints. No
rule claims them, since many carriers print eight-digit runs.

## Links

The tracking page reads the number from its form and loads the history from a JSON endpoint, so
no page address opens one parcel.
