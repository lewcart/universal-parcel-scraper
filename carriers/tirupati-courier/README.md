# Shree Tirupati Courier

Shree Tirupati Courier parcels use enabled universal providers. There is no dedicated adapter.

Shree Tirupati Courier Services is a domestic courier network in India.

## Numbers

The tracking field on the home page accepts digits and commas and asks for twelve-digit AWB
numbers. Lookups archived from the carrier's tracker show twelve-digit numbers, and lookups
archived from its older tracker show ten-digit docket numbers. Digit runs of these lengths are
printed by many other carriers, so no rule claims them.

## Links

The current tracker opens a result page whose address carries an encoded value instead of the
number, so no address opens one parcel. Lookups archived from the older tracker pages carry the
number as `docno` on `Frm_DocTrack.aspx` and `frmtracking.aspx`; the number is read from them.
