# TopDelivery

TopDelivery parcels use enabled universal providers. There is no dedicated adapter.

TopDelivery (ТопДеливери), run by Internet Logistika LLC in Moscow since 2011, delivers online shops'
orders to the door and to pickup points in the Moscow region and other Russian regions. Its site is
topdelivery.ru.

## Numbers

Its numbers are a counter of six to eight digits, which carries no sign of TopDelivery, so there is
no rule.

## Why there is no adapter

The tracker is an open page that answers the number alone, without a login; the CAPTCHA on the site
guards only its forms. It answers a public number with its scans. An adapter can follow.

## Links

Tracking links carry the number as `order` on the `tracking` page at topdelivery.ru.
