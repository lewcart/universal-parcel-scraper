# Rider

Rider parcels use enabled universal providers. There is no dedicated adapter.

Rider, a company of Pakistan's TPL group based in Karachi, delivers online shops' orders to their
customers in Pakistan. Its tracker is track.withrider.com.

## Numbers

Its tracker takes consignment numbers that start with WR or DZ and have at least seven more letters
or digits. No public number is known, so there is no rule.

## Why there is no adapter

The tracker asks an open JSON service without a session, which answers an unknown number with not
found. No public number has shown a known parcel's reply yet.

## Links

Tracking links carry the number after `#/track/` in the tracker's address.
