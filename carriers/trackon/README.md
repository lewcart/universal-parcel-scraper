# Trackon Couriers

Trackon Couriers parcels use enabled universal providers. There is no dedicated adapter.

Trackon Couriers is a domestic courier network in India.

## Numbers

The tracking field takes up to twelve characters. Customers quote twelve-digit numbers and
older ten-digit ones. Digit runs of these lengths are printed by many other carriers, so no
rule claims them.

## Links

The home page's search markup declares `trackon.in/courier-tracking?awb={number}` as its search
address, so that address opens one consignment. The tracking forms themselves post the number.
