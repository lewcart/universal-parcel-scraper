# trans-o-flex

trans-o-flex parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

trans-o-flex support quoted two numbers on the O2 help forum, each eleven digits, a hyphen and
thirteen digits. Without the hyphen they are twenty-four digits, a length other carriers share,
so no rule claims them.

## Links

trans-o-flex tracks shipments only after signing in, so there is no public search page.

## Testing

Provider live-test inputs and commands are in the [provider READMEs](../../providers/README.md).
