# TSB

TSB parcels use enabled universal providers. There is no dedicated adapter.

TSB is a Spanish business-to-business network for industrial parcels, run by
Transdina Cargo, with international services across Europe. Its site is tsbtrans.com and its
shipment tracker is on tsbconnect.net.

## Numbers

No public page shows one of its shipment numbers, so there is no rule.

## Why there is no adapter

The public tracker is a single-page application that asks Transdina's service for a shipment by
its number. No public number has shown a known shipment's reply yet.

## Links

The tracker opens from a search form; no shipment link format is known, so links are not read.
