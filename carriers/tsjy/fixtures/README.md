# Fixtures

`at-line.json` and `relayed-journey.json` follow the reply of the order search's
`track/query` lookup. The first is an order 17FEIA's warehouse holds: TSJY's own steps with
millisecond stamps, 17FEIA's relayed rows in whole seconds and the line's number. The second
carries the order on through 17FEIA's flight and customs milestones, its estimated departure,
a repeated row and a partner's relayed delivery; those later rows follow 17FEIA's wording.
`not-found.json` is the answer for an unknown order.

Numbers, ids, places and clocks are invented.
