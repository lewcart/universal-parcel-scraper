# TST-CF Express

TST-CF Express shipments use enabled universal providers. There is no dedicated adapter.

## Numbers

TST-CF Express PRO numbers are ten digits, as its tracing guides and an archived lookup on its
tracker show. Many carriers print ten digits, so no rule claims them. Freight shipped from the
United States carries a PRO number of TST-CF's partner Saia instead.

## Links

TST-CF's URL tracing guide sends the PRO number as `PRO` to
`tst-cfexpress.com/tracing/by-url`, which redirects to the result for that shipment.
