# TufesaPack

TufesaPack parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

TufesaPack is the parcel service of the Tufesa coach line, formerly sold as Tufesa Envíos.
Customers who posted their tracking codes under its tracking announcement gave four letters
followed by six digits. C chez vous, Team Global Express and Border Express print the same
shape, and two samples are too few for a rule, so no rule claims it.

## Links

The site's home search opens `tufesapack.com/paqueteria/rastreo/captura` with the code in
`codigo`. The tracker there also takes codes typed into its own search field.
