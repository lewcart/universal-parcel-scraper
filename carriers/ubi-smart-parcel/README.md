# UBI Smart Parcel

UBI Smart Parcel shipments use enabled universal providers. There is no dedicated adapter.

## Numbers

UBI hands parcels to the destination's carrier. Its aggregator samples include a Royal Mail
`WC…GB` number and twenty-three-character Australia Post barcodes, which those carriers'
rules claim. A sixteen-digit sample is not distinctive.

## Links

UBI's public tracker is the `#/ubi` page of its shipper portal, which reads numbers from
`?trackingNos=` after the hash.
