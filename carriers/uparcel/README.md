# uParcel

uParcel parcels use enabled universal providers. There is no dedicated adapter.

uParcel, run by MXHL Pte Limited in Singapore since 2015, delivers parcels on demand and the same
day with freelance drivers in Singapore and Malaysia. Its site is uparcel.sg.

## Numbers

Its tracker takes codes of six to sixteen letters, digits and hyphens and gives no layout or
example. No public code is known, so there is no rule.

## Why there is no adapter

Its terms of use forbid automated access.

## Links

Tracking links carry the code as `tracking-code` on the tracking page.
