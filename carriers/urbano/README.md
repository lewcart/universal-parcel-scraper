# Urbano

Urbano parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Urbano's own guías are a `G` and eight digits; archived lookups on its e-tracking page also
show eight-digit numbers and merchant order references with letter prefixes, which the
tracker accepts in place of a guía. `urbano-1` suggests Urbano for the `G` layout and stays
low because a letter and eight digits is a generic shape. Eight digits say nothing about the
carrier, and the merchant references stay quarantined.

## Links

`urbano.com.pe/tracking/` followed by the number opens one shipment. The older e-tracking
page on `app.urbano.com.pe` reads it from `?guia=`.
