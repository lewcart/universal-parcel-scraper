# Urvaam

Urvaam parcels use enabled universal providers. There is no dedicated adapter.

Urvaam is a last-mile delivery company in Madrid that delivers parcels sent from China, among
them YunExpress shipments.

## Numbers

Urvaam tracking numbers are sixteen digits starting `27` or `28`, seen in public consumer
complaints and an archived lookup on Urvaam's tracker. Sixteen digits are shared with several
carriers, so no rule claims them. The tracker shows the sender's reference, such as a
YunExpress number, as the customer number; that number belongs to the sender's carrier.

## Links

`www.urvaam.es/track/result?no=` followed by the number opens one parcel; the search page
builds that address.
