# Valueway Express

Valueway Express parcels use enabled universal providers. There is no dedicated adapter.

Valueway Express (美通快递), based in Toronto, ships parcels and online shopping between Canada and China,
with a line to Hong Kong. Its site is valueway.net.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

Its home page posts the numbers as `cno` to an Emmis tracker on member.valueway.net without a login. No
public number is known to see a found reply.

## Links

Its tracker looks numbers up by posting a form, so no address names one.
