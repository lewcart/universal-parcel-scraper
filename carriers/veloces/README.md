# Veloces

Veloces parcels use enabled universal providers. There is no dedicated adapter.

Veloces is a Colombian delivery network built for e-commerce and dropshipping shops. It also
operates in Mexico, Ecuador and Chile, working with allied local couriers.

## Numbers

Veloces guide numbers are `V` followed by ten digits. The UPS and DTDC rules already offer that
shape, so no rule claims it for Veloces.

## Links

`tracking.veloces.app/tracking-client/{number}` opens one guide; the tracker's search form
builds that address.
