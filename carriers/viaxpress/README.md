# ViaXpress

ViaXpress parcels use enabled universal providers. There is no dedicated adapter.

ViaXpress (VIAXPRESS LOGISTICS S.L.), based in Quart de Poblet, Valencia, is a network of
franchised couriers that deliver the same day in the Valencian Community and the Region of
Murcia, and further through partners in Spain and Portugal. Its site is viaxpress.es.

## Numbers

Its tracker takes the label code or the delivery note number. No public page shows one, so there
is no rule.

## Why there is no adapter

The tracking page posts the code with a page token and an invisible reCAPTCHA. No public code
has shown a known parcel's reply yet.

## Links

The links in its text messages carry a personal key, so no rule reads them. The tracking page
posts its form.
