# Viet An Express

Viet An Express parcels use enabled universal providers. There is no dedicated adapter.

Viet An Express (Việt An Express) sends parcels from Ho Chi Minh City and Hanoi to the United
States, Australia, the United Kingdom, the European Union and Asia. Its site is
vietanexpress.com.

## Numbers

Its own numbers are seven digits, given in sequence, so there is no rule.

## Why there is no adapter

The tracking page answers almost any seven-digit number with a shipment, so an answer does not
show that a number is the reader's parcel.

## Links

Tracking links carry the number as `tracking_num` on the tracking page.
