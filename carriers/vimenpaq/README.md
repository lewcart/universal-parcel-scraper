# Vimenpaq

Vimenpaq parcels use enabled universal providers. There is no dedicated adapter.

Vimenpaq is a Dominican courier of Grupo Vimenca. It runs mailboxes in Miami and Spain for
shoppers in the Dominican Republic and ships between its branches in the country.

## Numbers

Its tracker takes a guide number, a tracking number or a warehouse receipt. The only public
number seen is four letters and nine digits, from a customer's question. That is too little to
claim a layout, so no rule is proposed.

## Links

The tracker runs on the Controlbox platform and posts the number in a form, so no address opens
one parcel.
