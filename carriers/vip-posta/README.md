# VIP Posta

VIP Posta parcels use enabled universal providers. There is no dedicated adapter.

VIP Posta (Вип Пошта) is a licensed postal and courier operator in North Macedonia, based in
Skopje, which delivers documents and parcels for people, businesses and online shops through
about thirty branches. Its site is vipposta.mk.

## Numbers

Its tracker takes a shipment's serial number. A made-up number brought up another shipment, so
the numbers run in sequence and there is no rule.

## Why there is no adapter

The tracker answers almost any number with a shipment, so an answer does not show that a number
is the reader's parcel.

## Links

Tracking links carry the number as `id` on the tracking page.
