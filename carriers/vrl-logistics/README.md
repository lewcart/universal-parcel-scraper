# VRL Logistics

VRL Logistics parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

VRL tracks a consignment by its LR (lorry receipt) number, nine or ten digits. Digit runs of
these lengths are shared with other carriers, so no rule claims them.

## Links

The current tracker takes the LR number in a form post. Former VRL tracking pages carried it
in their addresses, and those addresses are recognized.
