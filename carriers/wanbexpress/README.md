# WanbExpress

WanbExpress parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

An aggregator page prints a WanbExpress number, `WNB`, two letters, ten digits and `YQ`;
one sample does not establish a rule. Its twenty-digit sample matches DHL's label shape.
