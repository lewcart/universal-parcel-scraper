# Wangjing 3CQ

Wangjing 3CQ parcels use enabled universal providers. There is no dedicated adapter.

Wangjing 3CQ (旺鲸3CQ), run by Shenzhen Wangjing Technology, ships online orders from China to Brazil. Its
site is wjdrop.com.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

Its tracker on track.wjdrop.com reads the numbers from the address and needs no login. No public number is
known to see a found reply.

## Links

Tracking links carry the number as `nums` on its `tracking/index` page.
