# Welivery

Welivery parcels use enabled universal providers. There is no dedicated adapter.

Welivery, run by Welivery SAS in Buenos Aires, with companies of the same name in Chile and
Colombia, stores online shops' stock and delivers their orders the same or the next day, including
Mercado Libre's Flex orders, and handles returns and business deliveries. Its site is
welivery.com.ar.

## Numbers

Its tracker takes the code sent by e-mail, SMS or WhatsApp and gives no layout or example. No public
code is known, so there is no rule.

## Why there is no adapter

Its terms of use forbid automated access.

## Links

Tracking links carry the code as `code`, or the older `wid`, on the tracking page.
