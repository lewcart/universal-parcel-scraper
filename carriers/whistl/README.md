# Whistl

Whistl parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Whistl publishes no number shape. Reviews, lookups archived from its tracker and aggregator
pages show references starting `L`, `TYPQ`, `s`, `a` and `011B`, of fourteen to
twenty-two characters, and an Evri barcode that Whistl may have handed over. No rule claims
them.

## Links

Whistl's site links parcel tracking to its ParcelHub tracker, which opens a number at
`web.parcelhub.net/Tracking/reference/{number}`. Archived links from Whistl's own
`trackmyitem.whistl.co.uk` put the number in the path of `/tracking/`.
