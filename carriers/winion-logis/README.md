# WINION LOGIS

WINION LOGIS parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

WINION LOGIS (위니온로지스) delivers small and heavy parcels in Korea, including AliExpress orders
after customs clearance. It passes some parcels on to partner carriers such as Kunyoung, Logen,
Kyoungdong, Ilyang and CJ Logistics, which then track them under their own numbers.

Its tracker takes ten to fourteen digits. Customers report twelve-digit waybills starting 1206
for AliExpress parcels; older waybills started WL. Twelve digits are a shape many carriers
share, so no rule claims them.

## Links

The home page's lookup reads the number from `num`, so
`winionlogistics.com/home.html?num={number}` opens one parcel. The former tracker at
`winionlogis.com/Trace.do?T={number}` now redirects to the home page.
