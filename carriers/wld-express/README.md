# WLD Express

WLD Express parcels use enabled universal providers. There is no dedicated adapter.

WLD Express (万立德), run by Shenzhen Wanlide International Logistics and Guangzhou Wanlide Supply Chain,
ships cash-on-delivery parcels from China to Europe, Japan and Southeast Asia. Its site is wld-express.com.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

Its track query on wld-exp.com, its order system, takes up to 40 numbers without a login. No public number is
known to see a found reply.

## Links

Its track query looks numbers up in place, so no address names one.
