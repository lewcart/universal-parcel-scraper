# XDP

XDP parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

XDP consignments are `ZDB`, three letters and six digits. Reviews, complaints and lookups
archived from XDP's own tracker show them; one complaint prints a leading zero. `xdp-1` claims
the shape with or without that zero. A complaint also calls a twelve-character hexadecimal
value its tracking, which no rule claims.

## Links

XDP's tracker asks for the consignment number and a postcode, so the user enters both there.
Archived links put the consignment in the path of `xdp.co.uk/track/` or in `c` on
`track.php`.
