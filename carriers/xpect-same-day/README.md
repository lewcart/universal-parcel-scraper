# Xpect Same Day

Xpect Same Day parcels use enabled universal providers. There is no dedicated adapter.

Xpect Same Day, in Inchicore, Dublin, delivers online orders within Dublin the same day, in three
waves seven days a week, and also offers next-day delivery across Ireland, express point-to-point
deliveries and returns. Its site is xpectsameday.com.

## Numbers

Its tracking ids reach recipients in tracking links and look like per-shipment link tokens rather
than printed numbers. No public id is known, so there is no rule.

## Why there is no adapter

Its tracker opens a shipment only from the id in the recipient's tracking link, which looks like a
token for that shipment.

## Links

Its tracking links carry what looks like a per-shipment token, so there are no tracking links.
