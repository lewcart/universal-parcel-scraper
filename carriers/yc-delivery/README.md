# YC Delivery

YC Delivery parcels use enabled universal providers. There is no dedicated adapter.

YC Delivery (YCお届け便) is run by the Yomiuri Shimbun and the SBS Group. Yomiuri newspaper
branches (YC) deliver its parcels. SBS Sokuhai is the SBS Group's own delivery network and has
its own carrier with its own numbers and tracker.

## Numbers

The tracker asks for twelve or thirteen digits. Lookups archived from YC Delivery's own
tracker show twelve digits whose last digit is the remainder of the first eleven divided by
seven. Yamato, Sagawa and other Japanese carriers print the same shape, so no rule claims it.

## Links

`www.e1.yc-otodoke.com/inquiry/?deliveryNumber={number}` opens one parcel, as archived lookups
on the tracker show. The tracker page itself sends a form.
