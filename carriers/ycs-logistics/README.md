# YCS Logistics

YCS Logistics parcels use enabled universal providers. There is no dedicated adapter.

YCS音速物流 is a Taiwanese logistics company with its own delivery fleet and stations across
Taiwan. It also clears and delivers cross-border parcels.

## Numbers

YCS barcodes are digits only. Customers quote thirteen- and eleven-digit numbers when asking
about YCS deliveries. Many carriers print the same lengths, so no rule claims them.

## Links

YCS's [tracker](https://system.ycs-express.com/search_track) looks numbers up from the page, so
no address opens one parcel.
