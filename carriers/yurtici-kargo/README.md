# Yurtiçi Kargo

Yurtiçi Kargo parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Yurtiçi Kargo numbers in Şikayetvar complaints are twelve digits. Twelve digits are shared
with several carriers, so no rule claims them.

## Links

The tracker's own script reads the shipment code from `?code=` on
`yurticikargo.com/tr/online-servisler/gonderi-sorgula`.
