# Fixtures

The replies follow the tracking page's `/server` lookup for one number.

- `returned.json` is a parcel YWE took in at its Los Angeles hub, failed to deliver and returned
  to the sender. One scan is listed twice so the tests can show it is kept once. The failed
  delivery carries street lines so the tests can show they are left out.
- `no-history.json` is the answer for a number the tracker has nothing for.

Numbers, places, street lines and clocks are invented.
