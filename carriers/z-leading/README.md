# Z-Leading

Z-Leading parcels use enabled universal providers. There is no dedicated adapter.

Z-Leading is Shenzhen Z-leading International Logistics (中领国际), a Shenzhen forwarder with
express, DDP and warehousing lines, whose site is z-leading.com. Universal providers name it
Zhongling, as its own logo file does.

## Numbers

No public source shows a whole Z-Leading number, so the corpus is empty and no rule claims a
layout. A parcel a universal provider files under Zhongling opens with ZL and two more letters
before nine digits; one provider is the only source for that layout.

## Links

The site has no tracking page, so no link opens one parcel.
