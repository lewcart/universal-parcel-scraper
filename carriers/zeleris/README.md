# Zeleris

Spanish Zeleris parcels use enabled universal providers. There is no dedicated adapter.

## Numbers

Zeleris codes are eighteen characters: eight hexadecimal characters, nine digits and a letter.
Two public OCU complaints quote them, and `zeleris-1` claims the layout. Sender references of
`ES`, a year, `COM` and ten digits are not Zeleris numbers.

## Links

Zeleris's tracking form sends the number to `zeleris.com/detalle-de-envio?tracking_number={number}`.
