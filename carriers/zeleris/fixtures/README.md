# Fixtures

`delivered.html`, `undelivered.html` and `depot.html` follow the shape of the page Zeleris's
tracker renders for one shipment: the search form with the number filled in, the code the page
answers for, the progress rail (with the copy the page leaves in a comment) and the messages to
the recipient, newest first. Codes, dates and clocks are invented. In `delivered.html` the page
prints the code with a later admission date than the one requested.
